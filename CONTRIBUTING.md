# Contributing to D Code

D Code does not currently accept external source code, design, branding,
asset, or documentation contributions.

You may use GitHub Issues to report defects or share feedback. Please do not
submit copyrighted material, private data, credentials, or code that you are
not authorized to disclose. A future contribution program, if any, will use a
separate written contributor agreement before material is incorporated into
D Code.

stated in [LICENSE](LICENSE), GitHub's Terms of Service, applicable law, and
the separate licenses governing third-party components.
