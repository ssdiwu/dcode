# 0.0.8 扩容：dgoal 融入（呈现 + 批准卡）

按你的两个决定执行：本地 `v0.0.8` 标签删除，已交付的工程内构与 dgoal 融入合并为同一个 `0.0.8`，收口时重新打标；融入深度为"呈现 + 批准卡"，不做内嵌分发。

## 现状基础（已核实，增量比预想小）

- dgoal 把工作状态持久化为会话 JSONL 的 `dgoal-work-v1` custom 条目；Host 无白名单原样透传，且 `pi-host.ts` 的 `planFromEntry` 已识别它并发 `plan.changed`。
- Swift `ActivePlanParser` 已解析 goal/objective/items/phases/blockedBy，ActivePlan 胶囊已在渲染。
- dgoal 启动门禁用标准 `ui.select` 对话框 → D Code 的 `extension.request`/`extension.respond` 原生对话框链路已通。
- 授权/升级消息（`/dgoal review`、自然语言授权）就是普通 prompt，走既有发送通道。

## 实施内容

**1. Plan Contract 呈现补全（Swift 解析 + 视图）**
- `ActivePlanParser` 扩展解析 `contract`（profile、transitions 升级历史、acceptanceCriteria、goalCheck 状态）、phase `acceptanceCriteria` + `check`（approved/rejected/audit_error + 审核 model）、item `evidence`/`deliverableEvidence` 摘要、`pauseReason`、`startedAt/updatedAt` 耗时。
- `ActivePlanView` 详情与 Work Inspector"活动计划"区补 profile 徽标、阶段验收与审核状态、证据摘要、暂停原因、耗时；胶囊本体保持紧凑。
- soft（无 contract）如实标"软性清单"，不伪装执行保障。

**2. 批准卡（Interaction Dock）**
- 解析 work-v1 的 `pendingProposal`：有待批的 goal_plan/staged_plan 提案时，Composer 交互坞显示原生卡片（目标、目标 profile、验收标准、升级来源）。
- 动作：批准/拒绝/反馈按钮通过既有 `session.prompt` 通道回传 dgoal 期待的授权输入（实现时以 dgoal `authorizeExplicitPlanUpgrade` 与 review 流的精确输入协议对齐）；运行中遵循既有排队/介入选择。
- startup gate 的 `ui.select` 对话框路径保持不动；批准卡只是把"待批提案"从对话流提升为一等原生交互，不建第二控制面。

**3. Host 侧小改**
- 核实 `planFromEntry` 是否原样透传完整 goal JSON（是则零改动）；为 Inspector 的历史摘要透传 `dgoal-plan-history-v1` 终局记录（最近一条 summary），保持无白名单原则。

**4. 版本与文档**
- 删本地 `v0.0.8` 标签；`0.0.8` = 工程内构 + dgoal 融入，收口重打标（不 push，等你指令）。
- PRD 0009 扩容范围；版本演进表 `0.0.8` 行改为合并描述（Project Trust 等顺延保持现状）；ZCode 吸收表 dgoal 行的版本边界从 `0.2.x` 改为 "`0.0.8` 呈现 + 批准卡，`0.2.x` 保留 Goal/Work Map 产品对象化"。
- 新增 ADR 0017：dgoal 融入边界——D Code 识别其结构化状态并原生呈现/回传授权，dgoal 仍由用户 Pi 配置加载（非 D Code 运行时依赖，不破 AGENTS.md 现有边界），TUI PlanOverlay 显式忽略。

**5. 验证**
- 单测：ActivePlanParser 对 dgoal 真实形状 fixture 的 contract/check/evidence/pendingProposal 解析；Fake-host 集成用例（plan.changed 驱动呈现状态、批准卡出现/发送授权消息经 `session.prompt`、提案消失）。
- 渲染冒烟：带 contract 的 ActivePlanView、批准卡两种状态。
- 终验门禁全套（swift test、host npm test、build.sh、diff check、链接）；真实 dgoal 会话手测（启动门禁、升级批准、阶段审核显示）留待人工验收并如实记录。
