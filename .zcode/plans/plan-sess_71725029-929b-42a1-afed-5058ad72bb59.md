# 0.0.10：Project Trust 与动作级 Permission

三项默认决策（未获答复，按推荐执行，可在批准时否决）：
1. **Bash 粒度**＝命令前缀 + 目录域（`npm test*`、`git *`）；文件写入按"Source Folder 授权根内"整体授权。
2. **默认策略**＝读取/列目录默认放行（沿用 0.0.4 授权根语义）；文件写入与 Bash 一律先问，命中已授权 grant 才放行；项目外目标写入永远单独问。
3. **管理面**＝权限卡片 + 设置页"权限"页（授权列表 / 撤销 / 最近审计记录）。

## 架构（可行性已核实）

Pi 0.84.1 无内置审批 API，但 `beforeToolCall` 钩子被 AgentSession 桥接为扩展 `tool_call` 事件（async 可挂起等待人工批准，返回 `{block, reason}` 拒绝）。Host 经 `createAgentSession({ resourceLoader })` 注入 inline 扩展（`dcode-fast` 已验证的模式）实现权限闸门。

## Host 改动（host/src）

1. **权限存储** `permission-store.ts`：`agentDir/pi-dcode/permissions-v1.json`（沿用租约目录先例），版本化文档 + 原子写：`grants[]`（id、kind=`bashPrefix|fileWrite`、root=授权时的会话 cwd、pattern/前缀、createdAt、createdBySession）与 `audit[]`（有界环形，最近 200 条决策：时间/会话/工具/摘要/决策/风险）。
2. **权限闸门扩展** `permission-guard.ts`：inline factory `api.on("tool_call")` → 读取类工具直接放行；写入/bash 查 grant 表（bash 按前缀 + cwd 匹配、写按目标路径在授权根内）；未决时 emit `permission.request`（id、工具、输入摘要、目标、风险分类）并挂起等待 `permission.respond`；`deny` 返回 `{block, reason}`；`allowScope` 持久化 grant；`allowOnce` 不持久化。会话关闭/冲突时未决请求全部以"会话已关闭"拒绝结算。
3. **风险分类**（卡片展示）：项目内写入 / 项目外写入（高） / 高风险命令（rm、dd、git push、`curl|sh`、sudo 等模式，高） / 一般命令。
4. **协议**：新方法 `permission.respond` / `permission.list` / `permission.revoke`，新事件 `permission.request` / `permission.updated`，新能力位 `permissionGate`；版本 0.0.10。

## Swift 改动（app/Sources）

1. **PermissionModel**（State/ 新域模型）：pendingRequest（工具、摘要、目标、风险、可选项）、grants 列表；`permission.request` 事件驱动，`permission.updated` 同步授权表。
2. **权限卡**（Composer 交互坞）：工具名 + 输入摘要（命令或文件路径）+ 风险徽标，三键"本次允许 / 当前目录范围允许（前缀） / 拒绝"；拒绝后模型收到错误 tool result 并如实呈现。
3. **设置页"权限"**：授权列表（类型/根/前缀/授予时间/来源会话）+ 单条撤销（`permission.revoke`）+ 最近审计记录（只读）。
4. 版本常量与文档同步 0.0.10。

## 验证

- Host：store CRUD/原子性；闸门流程（放行命中前缀、allowOnce 不持久化、allowScope 持久化并复用、deny 返回 block reason、挂起中会话关闭全部拒绝、读取类不询问）；协议校验用例。全量回归。
- Swift：Fake-host 集成（`permission.request` → 卡片状态 → 三种决策回传 `permission.respond` 参数正确 → `permission.updated` 更新列表）；渲染冒烟（权限卡两态、设置权限页）。全量回归。
- 真实手测留档：真实会话里触发一次 bash 与一次文件写入的询问流、前缀复用、撤销后再次询问。

## 文档

ADR 0019（Project Trust 与动作级权限：grant 语义、默认策略、风险分类、审计、无法强制时的诚实降级——闸门只在 D Code Host 内生效，Pi CLI 不受约束并如实说明）；PRD 0011；路由表、版本演进 0.0.10 行与决策门禁补 ADR 0019；CHANGELOG。
