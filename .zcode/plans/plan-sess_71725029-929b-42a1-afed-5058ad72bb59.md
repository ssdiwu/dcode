# 0.0.13：第一次 Self-build Loop（自构建闭环）

**协议核心（ADR 0022）**：构建产物与在用 App 物理隔离；替换与回滚只由用户显式触发的原子交换完成；重启后自动恢复原会话。

## 受控替换 / 回滚 / 重启协议

1. **构建隔离**：`app/build.sh` 增加 `PI_DCODE_DIST_DIR` 环境覆盖（默认 `dist` 不变）；D Code 的构建动作输出到 `dist-candidate/`——**在用 bundle 永不被构建过程触碰**。
2. **候选校验**：`codesign --verify`、Info.plist 版本、内嵌 Host `package.json` 版本一致性；任一不过即拒绝重启动作并如实报告。
3. **原子交换**：用户点"重启到候选"→ `mv dist/D Code.app → dist/D Code.app.backup`（仅保留一份，覆盖旧备份）→ `mv 候选 → dist/D Code.app` → 写 UserDefaults（`selfBuildRestart` + `pendingReopenSessionId`）→ `NSWorkspace` 打开新 App → 当前 App 走既有 terminate 关机流程。交换任一步失败 → 全量回退到交换前状态再报告，不自动重试。
4. **回滚**：设置页"回滚到备份构建"（存在备份时可用）——交换 backup 与当前后重启，同样协议。
5. **会话恢复**：启动时读 `selfBuildRestart` 标记 → 清标记 → Host 就绪后自动以打开即接管恢复 `pendingReopenSessionId` 会话。
6. **失败语义**：构建失败只报告输出尾部（保留最近 200 行），不动在用 App；无 watchdog / 崩溃自动回滚（诚实声明，首版闭环）。

## Swift 实现

1. `SelfBuildModels.swift`：`SelfBuildRunner`（Process 跑脚本，脚本路径可注入供测试；流式收集输出尾 200 行 + 时长）；`SelfBuildCandidateValidator`（签名 / 版本 / Host 一致性）；`SelfBuildBundleSwapper`（纯 rename 交换 + 失败回退，目录可注入）。
2. `State/SelfBuildModel.swift` + AppModel 协调：`startSelfBuild()`（busy 防重入）、`restartIntoCandidate()`（校验 → 交换 → 标记 → relaunch → terminate）、`rollbackToBackup()`；`PiDCodeApp` 启动恢复钩子。
3. Settings 新页"自构建"：构建按钮与状态、输出尾部（可展开）、候选卡（版本 / Host 版本 / 签名 ✓）、"重启到候选"（确认弹窗）、回滚入口、协议说明文案。

## 模型侧（闭环的另一半）

会话内改动 / 测试沿用既有工具与 0.0.10 权限闸门（`./app/build.sh` 经 bash 前缀授权）；0.0.12 证据账本自动记录验证命令。**0.0.13 交付机制；"至少一条真实任务完成构建-重启-恢复"的完成信号按路线留人工验收。**

## 验证

- 单测：Runner（echo 脚本替身，成功 / 失败 / 输出截断）、Validator（未签名假 bundle 拒绝；真签名场景留手测）、Swapper（临时目录交换 / 回滚 / 失败回退）、恢复标记状态机。
- 渲染冒烟：自构建设置页（构建中 / 成功 / 失败三态 + 候选卡）。
- 终验门禁全套 + commit + tag v0.0.13 + 推送。
