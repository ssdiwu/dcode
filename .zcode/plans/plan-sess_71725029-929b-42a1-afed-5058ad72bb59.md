# 0.0.11：只读 Exact Git Diff

勘察结论：Swift 已直跑 `/usr/bin/git`（GitModels 的 repo 去重 + porcelain status），`NativeDiffView` 已有逐行 +/- 渲染范式，变更入口在 WorkInspector"变更"Tab。**纯 Swift 侧演进，Host 与协议零改动。**

## 数据层（GitModels.swift 扩展）

1. `UnifiedDiffParser`：解析 unified diff → 文件级（新旧路径、isBinary、isRename）→ hunk（`@@ -a,b +c,d @@` 头 + context/增/删行，保留 a/b 行号）。护栏：单文件 diff > 512KB 或 > 3000 行 → 诚实截断并标注"仅显示前 N hunk"；二进制标"二进制文件"。
2. `GitDiffReader.fileDiff(repoRoot:path:)`：按需读取——`git -C <root> diff -- <path>`（unstaged）与 `git diff --cached -- <path>`（staged）分流解析，各自计数 +N/−N；untracked 文件展开时复用 WorkspaceFileReader（2MB/UTF-8 护栏）作"新文件"内容预览。全程只读（GIT_OPTIONAL_LOCKS=0 等既有环境约束不变）。
3. 展开结果按 (repoRoot, path) 缓存，repo 列表刷新时失效。

## UI（WorkInspector"变更"Tab）

1. `GitRepositoryCard` 文件行改为可展开（DisclosureGroup）：内分 **已暂存 / 未暂存** 两区（各有则显示，保持 staged/unstaged 语义诚实），每区 hunk 头（行范围）+ 逐行渲染（+绿 / −红 / 上下文次级色，a/b 双行号，等宽），复用 NativeDiffView/WorkspaceFileLinesView 的行渲染范式。
2. 文件行摘要 +N/−N（解析计数）；untracked 展示新文件预览。
3. 底部只读声明："真实 Git 差异 · 只读 · 不提供 stage/discard/commit"；与会话变更账本的区分文案互引（ActivePlanView 的"不是 Git 净差异"处链接到本 Tab）。

## 文档与版本

- ADR 0020《Git 差异事实来源》：Swift 只读直跑 `/usr/bin/git`，事实以 git 输出为准；与会话账本（结构化工具已确认）双轨并存、各自诚实；无任何写操作。
- PRD 0012；路由表、版本演进 0.0.11 行与决策门禁（Git 事实来源由 ADR 0020 固定）；CHANGELOG；版本常量两端升 0.0.11。

## 验证

- 解析器单测：多 hunk / 新文件 / 删除 / 重命名 / binary / 截断 fixtures。
- 读取器集成：临时目录初始化真实 git 仓库（修改 + stage + 再修改 + untracked），验证 staged/unstaged 分流、计数与 untracked 预览。
- 渲染冒烟：文件展开 diff 视图（含 staged/unstaged 两区）。
- 终验门禁全套 + commit + tag v0.0.11 + 推送。

## 范围外

stage/discard/commit/push 任何写操作、跨 repo 聚合视图、行内 blame、Host 侧改动。
