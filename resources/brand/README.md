## 唯一母版

[dcode-owl-master.png](dcode-owl-master.png) 为选定原图的原字节副本，1254×1254；SHA256、批准依据、来源及派生资源清单见 [manifest.json](manifest.json)。Git 中以此正式母版为准；未采用候选及原始探索记录保留在开发机器的 output 目录，不随客户端基线提交，不以重新生成的近似图替代母版。

## 使用约定

- 应用和界面使用同一母版及由其确定导出的资源。保留两只翅膀与完整代码符号；不回退到缺翼 R1，也不继续使用旧变色龙作为现行品牌。
- 原图的黑白主体、雾蓝背景及形状均为本次选择的一部分。不得把完整图片套用旧版单色 mask、主题反色或裁切而破坏它。雾蓝不自动成为整套界面的强调色。
- 品牌标志与文字共同出现时保留可辨的 D Code 名称；装饰图不新增操作入口，不用图形替代按钮的可访问名称。
- 保持宽高比；显示尺寸从现行字号尺度派生，并保留 macOS 原生窗控避让。母版保留完整底色；macOS 应用图标使用下面的平台资产，不能直接把满幅直角母版传给 Dock。
- 必要的平台尺寸导出须可追溯到此母版；导出、客户端接入、构建产物、Dock／Finder 实际显示和用户验收分别核实。当前仓库未因此新增打包器或发布能力。

这是已确认的品牌选型，不等于所有客户端入口已经替换。接入状态只由 [PROGRESS](../../PROGRESS.md) 维护；manifest 记录母版来源和派生资源，不维护第二份进度。

## macOS 应用图标

507 于 2026-10-09 指出 Dock 直角方图与相邻圆角图标不协调。[dcode-macos.png](dcode-macos.png) 是对已选母版的应用场景适配：保留猫头鹰、D 轮廓、双翼及代码符号，使用圆角雾蓝底和透明外边距，使 Dock 中的视觉尺寸接近相邻应用。由内置图像编辑基于母版生成，1254×1254，带透明通道；它不是逐像素蒙版导出，也不替换母版。

母版与应用图标分别保存，生成来源和哈希见 manifest。应用内标志沿用原母版；Dock／窗口图标读取平台资产。真实 Dock 呈现须另验，PNG 本身的圆角不能证明系统已加载新图标。
