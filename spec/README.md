# 产品规格

本目录统一保存 D Code 随产品迭代更新的具体功能、页面和 UI／UX 设计规格，说明用户操作、系统行为、页面与交互状态及验收条件。规格先行规则由 [AGENTS.md](../AGENTS.md) 规定。

同一功能优先更新已有规格，已经稳定的规格也继续在这里维护。规格中的目标、实现状态和验证结果分别标明；写完规格不代表功能已经实现或验收通过。

跨功能共用的体验与视觉规则见 [DESIGN.md](../DESIGN.md)，词义见 [GLOSSARY.md](../GLOSSARY.md)。长期参考、设计思考、长远版本规划及架构／使用说明进入 [doc/](../doc/README.md)，通过链接引用相关规格，不复制第二份规则正文。

当前实现、证据与缺口统一见[PROGRESS](../PROGRESS.md)；下表只记录已确认的规格范围。

| 规格 | 当前确认范围 |
|---|---|
| [页面与交互组件](页面与交互组件.md) | 逐页控件职责、显隐与可用条件、操作结果、失败及键盘边界；发送／暂停／继续同位切换及可恢复归档已确认 |
| [工作台信息架构](工作台信息架构.md) | 对象与内部协作、可恢复归档（首版无永久删除）、按风险安排独立审查；本机与远端空间同栏；统一快捷入口查找操作与任务；悬浮侧问及输入分流；远端统一连接、多端操作、设备配对、产品提供外网接入且中转不持正文解密钥匙；首批 Mac 执行端、Mac 桌面与手机浏览器访问 |
| [开发任务路径](开发任务路径.md) | 首条完整路径、可隐藏任务信息面板、Mac 底部内置终端且工作空间共用终端组、终端运行中退出提示与最近历史恢复、手机时间线与抽屉、首版只读协作图及共用验收场景；主动检索已有知识，记忆以 `memory/` 下 Markdown 保存，个人偏好跨空间、工作事实与经验默认归所属空间 |
| [冷启动与草稿态](冷启动与草稿态.md) | 启动两档、新草稿首发建立独立任务、草稿保存及缺模型配置提示 |
| [任务暂停与恢复](任务暂停与恢复.md) | 多任务并行与成员分工暂停；任一有效工作界面维持运行、最后界面离开后暂停保存；已暂停工作显式接续 |
| [模型选择与自动切换](模型选择与自动切换.md) | 预设供应商/自定义、联网模型信息与缓存已确认；会话自动/指定、能力优先、额度次之及等待明确继续保持 |
| [用量与账户额度](用量与账户额度.md) | 首版同时呈现任务用量及可可靠读取的账户信息；订阅额度、账户资金与任务统计分开 |

以上记录已确认的产品范围，并列出后续必须完善的部分；不代表已具备完整实施合同或通过验收。
