# 产品规格

本目录统一保存 D Code 随产品迭代更新的具体功能、页面和 UI／UX 设计规格，说明用户操作、系统行为、页面与交互状态及验收条件。规格先行规则由 [AGENTS.md](../AGENTS.md) 规定。

同一功能优先更新已有规格，已经稳定的规格也继续在这里维护。规格中的目标、实现状态和验证结果分别标明；写完规格不代表功能已经实现或验收通过。

跨功能共用的体验与视觉规则见 [DESIGN.md](../DESIGN.md)，词义见 [GLOSSARY.md](../GLOSSARY.md)。长期参考、设计思考、长远版本规划及架构／使用说明进入 [doc/](../doc/README.md)，通过链接引用相关规格，不复制第二份规则正文。
