# 产品与交互

本目录记录 D Code 跨版本持续逼近的产品目标、信息架构与交互契约。这里回答“最终要成为怎样的产品”，不证明这些能力已经实现。

## 权威边界

- `20-产品与交互/`：已经确认的目标形态与可交互参考。
- `40-版本实施方案/`：每个版本实际承诺交付和验收的切片。
- [`10-架构与运行/0002-D-Code-原生界面设计系统.md`](../10-架构与运行/0002-D-Code-原生界面设计系统.md)：当前原生界面的实现权威；根 `DESIGN.md` 只提供设计性格与文档路由。
- `原型/`：使用模拟数据表达交互；不得据此声称原生 App 已完成、测试通过或可发布。
