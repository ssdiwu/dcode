本目录只服务[独立 HTML 原型](../dcode-workbench-v2-prototype.html)，不进入正式客户端。

507 最新确认：**粒子只出现在新建任务页**。灵感页使用普通工作台画布，既不渲染粒子，也不创建对应 WebGL 实例。

## 原始来源

- [完整注册源码](https://threeui.com/source-code/structure-flow.json)，用户给定 revision `40eb5bac81e3`。
- `vendor/source-bundle.json` 保存本次完整响应；`vendor/src/` 的 5 个文件逐字保留。
- `build-provenance.json` 记录每个文件的 SHA-256、构建输入与所选参数。构建前重新验证原文哈希，不改写原版源码。
- 原始组件与依赖采用 MIT 许可，声明保留在 `vendor/LICENSE` 及生成 HTML 内的许可注释中。

## 接入方式

`scene.tsx` 使用指定的 `StructureFlowCollection`、`structure-flow` 变体以及 `speed=1`、`pointSize=0.08`、`opacity=0.4`、`maskStart=0.2`、`maskSolid=0.5`。

构建时，包入口映射到已核验的注册源码；集合声明的其他变体仍解析到锁定的官方 `@designcodeio/threeui@1.2.0` 实现。实际选中渲染器使用 `three128`（`three@0.128.0`），没有自绘替代或文档页嵌入。共享样式保留全部原文，其中其他组件使用的字体声明保持原路径；本变体不使用或请求该字体。

原版相机、15,000 个点、材质、遮罩、透明度与旋转保持不变。原型只负责背景容器、主题合成与页面生命周期：进入新建任务页挂载，离开该页或文档隐藏时卸载。再次进入重新创建场景，不声明恢复相同随机点序列。深色保留原版暗底白粒子，浅色仅给 `.structure-scene` 外层设置 `filter: invert(1)`，配合白底呈现黑粒子；前景卡片和文字不参与反相。

主题切换使用按钮当前矩形的中心作为圆形扩散起点，不依赖鼠标事件坐标；键盘及辅助点击也从同一按钮开始。按钮选中状态与全页配色进入同一次 View Transition。

## 重建

在本目录执行：

```sh
npm ci --ignore-scripts
npm run build
```

脚本仅替换 HTML 中 `threeui:style` 与 `threeui:script` 标记间的生成内容，其余界面继续在 HTML 中编辑。输出内联 React、Three.js 和所需组件，仍可通过 `file://` 直接打开。
