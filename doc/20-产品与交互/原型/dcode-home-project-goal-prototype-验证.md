# D Code 项目优先主页与真实能力入口：原型验证

状态：Direction Confirmed（方向已确认；原型保留为人工走查参考，不构成 App 验收）

## 验证问题

将首页的裸目录选择替换为唯一的 `Project（项目）` 选择器（项目与目录一一对应，首页不暴露目录），并把具体的文件、Skill、命令、目标与计划都收进 `+` 菜单后，用户是否能在开始输入前理解：这项工作属于哪个项目、能做什么，以及项目改目录时会发生什么？

## 假设与信号

- 假设：只显示项目名的下挂条，比裸 `~` 或路径更清楚地表达会话、文件与历史的共同归属。
- 支持信号：507 能不经解释指出“下方只选项目；目录只在项目编辑时出现；项目改目录时会直接改写相关会话的 `cwd`，文件是否同行是第二步选择”。
- 否定信号：507 仍认为首页需要路径辅助，或无法区分 `+` 菜单中的文件、Skill、命令、目标与计划。
- 边界假设：`+` 承载具体动作；目标与计划的能力来源由系统内部识别，但产品标签不附带来源名；不出现插件、扩展、本机资源或网页预览入口。

## 运行方式与范围

- 直接打开 [交互原型](dcode-home-project-goal-prototype.html)。
- 推荐试玩顺序：点击项目条 → 选“Curio” → 打开“管理项目” → 选择新目录 → 分别尝试勾选与不勾选“同时迁移目录内文件”；再打开 `+` 试玩文件、Skill、命令、目标与计划。
- 所有项目、文件、附件、资源与计划状态均为内存模拟；不读取 Pi 配置、真实项目文件、凭据或会话，也不会写入或改写真实 `cwd`。

## 观察

- 尚待 507 的主观试玩判断。
- 自动冒烟目标：页面可加载；项目切换、新建项目模拟、目录修改 / 文件迁移二次选择、模型切换、附件 chip、目标预填、计划示例、Skill / 命令面板与 Esc 关闭均可操作。
- 2026-08-23：浏览器冒烟已复验新结构：首页只有一个项目选择器且不暴露目录；`+` 只显示“添加文件或图片 / Skill / 命令 / 目标 / 计划”；目标预填不显示来源名；计划可展开；改目录的“仅改写会话 cwd”和“同时迁移目录内文件”两种模拟结果均可分别触发。任何原型通过都不构成 Swift App 验收。
- 2026-08-23（隔离外部使用）：在 `1280 × 633` 浏览器画面中，3 个隔离 case 的首屏都没有看见项目条；一个 case 能从 `+` 成功添加图片、选择 Skill 并准备任务，另一个能找到计划，但目录迁移 case 在 9 个自然步骤内找不到项目编辑入口而放弃。完整 trace、截图与反馈保存在 `/Users/diwu/.mirasim/eval/sessions/260823-1447-dcode-project-prototype/`，不含真实 Pi 或项目数据。
- 2026-08-23（修复复验）：短窗口下将首页 Composer 区压缩到项目条同屏，移除项目条残留 `⌄`、移除第二个“从文件夹新建项目…”入口，并合并为“添加文件或图片…”。隔离浏览器复验在同一 `1280 × 633` 视口直接读到 `D Code` 项目按钮；打开后可读到 `Curio`、新建项目和“管理项目…”，后者可进入“修改项目目录”并看到独立的“同时迁移目录内文件”选择。该复验只证明 HTML 原型路径，原生 App 仍待人工验收。
- 2026-08-23（模型与菜单修正）：在隔离浏览器 `1440 × 900` 视口中，Composer 可访问树同时出现“添加操作 / 选择模型 / 配置推理强度 / 发送”；模型菜单列出 GPT-5.6 Sol / Luna，`+` 展开后只有添加文件或图片、技能、命令、目标、计划。菜单已移除大标题、说明段与胶囊按钮式布局；Skill 列表显示普通名称与说明、不显示 `/skill:`，原型输入框可把剪贴板图片转成附件 chip。原生 Swift 使用系统 Menu，实际 macOS 菜单与真实 Cmd-V 仍需 Candidate 人工核对。

## Verdict

- direction-confirmed：主页只选择 Project，项目与目录一一对应；改目录原地迁移会话 `cwd`，文件迁移是独立开关。
- Composer 显示 `+`、无 CPU 图标且无外露箭头的模型名选择、独立推理强度与发送。`+` 使用紧凑菜单，不显示面板标题、说明段或胶囊按钮，也不出现插件、扩展、本机资源、网页预览或浏览器控制；Goal / Plan 不暴露来源名。
- 原型的短窗口发现性缺口已按隔离浏览器证据修复；模型入口与 `+` 容器的后续误读由 PRD 0025 / ADR 0033 修正并落入本机代码，真实 App 菜单人工验收仍待完成。
