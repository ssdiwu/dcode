[Raven固定版本](https://github.com/EverMind-AI/Raven/tree/3632e6040c7038a60ec418ce39ccae185c72c19f)只借只读协作关系、状态和详情，不引入流程编辑器或审批；Motion Panels只作明确布局缺口的候选，CC-Usage-Band只借轻量信息层级，不证明数据接入。相关取舍与复评材料在[参考评估](灵感库对照审查.md)，具体组件消费者见[ZCode研究](ZCode-交互组件借鉴.md)。

React Bits只限功能动效，Vue等不同框架材料不直接移植；许可随具体版本/文件核对，不凭主分支许可页替导入登记。库已存在不构成替换理由。
