## 分类判据

- 拿掉后项目—任务—会话—Agent 运行主干或所有能力共同合同无法成立：基础能力。
- 只服务部分任务，或拥有独立账户、权限、持久对象、额度与生命周期：可选一等拓展。
- 只为一项能力提供具体模型、网络、凭据或本机实现：提供方或内部适配。
- 没有独立状态与生命周期的一次性窄操作：Skill 或工具。
- 高度绑定 Pi TUI、Pi 包生态或临时验证过程，且用户结果已被 D Code 其他能力拥有：不迁移，只吸收机制。
