# D Code 0.0.13 第一次 Self-build Loop 产品需求

状态：Implementation Candidate（实现候选，待人工验收）

本 PRD 冻结 `0.0.13` 的范围与验收边界；受控替换 / 回滚 / 重启恢复协议以 [ADR 0022](../决策档案/0022-自构建与受控重启协议.md) 为准。

## Problem Statement（问题陈述）

`0.1.0` 晋升需要 D Code 在自己的会话内完成"改动 → 验证 → 构建候选 → 受控替换 / 重启 → 回到原任务"的闭环；当前构建只能在外部终端执行，替换在用 App 没有任何受控机制。

## Solution（解决方案）

`app/build.sh` 参数化产物目录；设置新增"自构建"页：构建候选（输出到 `dist-candidate`，不触碰在用 App，输出尾部 200 行可查）→ 候选卡（App / Host 版本一致性 + 签名校验）→ "重启到候选"（确认后原子替换 + 单备份 + 恢复标记 + 拉起新 App）→ "回滚到备份构建"（同协议反向）。新 App 启动时消费恢复标记并按打开即接管恢复原会话。会话内改动 / 测试 / 构建脚本执行沿用权限闸门与证据账本。

## Confirmed Constraints（已确认约束）

- 在用 App 在构建全程不被触碰；替换与回滚只经用户显式确认的原子交换，失败全量回退不自动重试。
- 候选校验不通过（签名 / 版本缺失或不一致）禁止重启动作。
- 无后台静默更新、无 watchdog / 崩溃自动回滚；备份只保留一份。
- "一次成功"不表述为稳定自迭代；真实任务闭环是人工验收信号。

## Acceptance Criteria（验收标准）

- [x] Runner：成功 / 失败 / 启动失败输出、环境变量（PI_DCODE_DIST_DIR）传递（用例）。
- [x] Swapper：无 active 直接安装、替换留备份、回滚互换、候选缺失如实报告（用例）。
- [x] Validator：缺 Info.plist / 缺内嵌 Host 版本拒绝（用例；真签名候选属真实手测）。
- [x] 恢复标记一次性消费（用例）；设置页三态渲染冒烟。
- [x] `swift test`（186 用例）、`cd host && npm test`（131 用例）全绿；版本 0.0.13。
- [x] `./app/build.sh` 产出 `dist/D Code.app`（0.0.13，435M，签名通过），内嵌 Host 与 App 版本核验为 `0.0.13`。
- [ ] 真实环境手测（= 第一次真实闭环）：在 D Code 会话内做一次小改动 → 测试 → 设置页构建候选 → 重启到候选 → 新 App 自动恢复原会话 →（可选）回滚到备份。

## Verification Record（验证记录）

- 2026-08-20：机制实现与自动测试完成（Swift 186/186、Host 131/131）；版本常量升至 0.0.13。bundle 重建成功（435M，签名通过，包内版本一致）；第一次真实闭环留待人工执行（本 PRD 的核心完成信号）。

## Out of Scope（不进入本版）

后台静默更新、watchdog / 自动回滚、多备份历史、自动连续自迭代宣称、发布自动化。
