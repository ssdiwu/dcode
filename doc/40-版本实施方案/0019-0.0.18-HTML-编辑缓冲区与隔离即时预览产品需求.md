# D Code 0.0.18 HTML 编辑缓冲区与隔离即时预览产品需求

状态：Implemented（自动门禁已通过；人工验收待完成）

本 PRD 冻结 `0.0.18` 的范围与验收边界；编辑缓冲区、原子保存与冲突边界沿用 [ADR 0025](../决策档案/0025-Markdown-编辑缓冲区与原子保存边界.md)，预览沙箱与网络策略由 [ADR 0026](../决策档案/0026-HTML-隔离即时预览与网络询问边界.md) 固定（用户裁决：脚本默认允许、仅禁联网、联网尝试询问）。界面语义以 [`0002-D-Code-原生界面设计系统`](../10-架构与运行/0002-D-Code-原生界面设计系统.md) 为准。版本演进对应路线图 `0.0.18`（HTML 编辑缓冲区与隔离即时预览）。

## Problem Statement（问题陈述）

`0.0.17` 建立了编辑缓冲区但只覆盖 Markdown：HTML 文件仍只能只读行渲染，核对动态页面要切外部浏览器，预览与缓冲区事实割裂，外部浏览器又不受 D Code 资源边界约束。路线图 `0.0.18` 要求 HTML 从只读进入编辑缓冲区并具备隔离即时预览——未保存 HTML 可预览，但不能借预览越过 Source Folder 授权与资源边界；原型的"未开放脚本权限"静态形态经用户裁决调整为"脚本默认允许、仅禁联网、联网尝试询问"。

## Solution（解决方案）

1. **HTML 编辑（复用 0.0.17）**：`.html` / `.htm` 文件打开即建立编辑缓冲区（基于快照，进入"编辑缓冲区 | 即时预览"双栏）；修改、⌘S 保存、冲突三选、关闭 / 放弃确认、授权撤销语义与 Markdown 完全一致（ADR 0025），无第二套模型。
2. **隔离即时预览（WKWebView 首例，ADR 0026）**：预览内容从**内存缓冲区**注入（编辑停顿约 400ms 节流自动重注入），不读磁盘、不冒充已写盘；`websiteDataStore = .nonPersistent()`、禁新窗口与下载；`javaScriptEnabled = true`（内联脚本可运行，运行在沙箱 web 进程内）。
3. **网络默认阻断 + 询问**：WKContentRuleList 阻断全部 `http(s)` 子资源；WKNavigationDelegate 拦截外部导航并触发预览头部询问条（"该页面尝试联网，已阻止 / [本次允许] [保持阻止]"）；子资源以常驻"联网资源：已阻止 · [本次允许]"状态呈现（WebKit API 无法逐条询问，如实标注）。"本次允许"仅当前预览会话有效，切换文件或重启恢复阻止。
4. **本机资源限定授权根**：baseURL 为自定义 `dcode-asset://` scheme；HTML 相对资源引用经 `WKURLSchemeHandler` 回到 Swift，复用安全路径（逐级 `openat`、`O_NOFOLLOW`、限 Source Folder 授权根）读取并按扩展名返回 MIME；越界路径、符号链接、缺失文件请求直接失败。
5. **双栏形态**：HTML 文件打开即并排双栏（窄窗口上下堆叠），无源码 / 预览切换；左栏头部为编辑缓冲区与脏状态，右栏头部为"即时预览 · 跟随未保存缓冲区 · 联网策略"。

## Confirmed Constraints（已确认约束）

- 全部服从 ADR 0026：不提供地址栏 / 前进后退 / 自由浏览（不是浏览器）；联网放行仅会话内、仅资源加载；不做持久联网授权；预览不自动进入模型 Context。
- 编辑上限沿用 2MB 与二进制 / UTF-8 检测；冲突与保存语义沿用 ADR 0025。
- WKWebView 内部渲染行为不在自动测试范围；以配置断言、scheme handler 安全校验单元测试与人工验收收口。

## Acceptance Criteria（验收标准）

- [x] HTML 文件打开即双栏编辑：左编辑右预览、⌘S 保存、脏标识、关闭确认、冲突三选与 Markdown 一致；窄窗口堆叠（打开即 draft 由 `loadWorkspaceFile` 成功点自动建立，集成用例锁定；双栏与询问条渲染冒烟通过）。
- [x] 即时预览跟随缓冲区：编辑停顿（约 400ms）后自动重注入 `loadHTMLString`；头部常显"跟随未保存缓冲区 / 与磁盘一致"，不冒充磁盘事实。
- [x] 内联脚本默认运行（`allowsContentJavaScript = true`，nonPersistent 隔离存储）；WKWebView 内部渲染行为按约束归人工验收。
- [x] 网络默认阻断：内容规则阻断全部 `http(s)` 子资源；外部导航一律拦截并触发询问条（[本次允许] / [保持阻止]）；"本次允许"移除规则并重注入、仅当前文件会话有效，切换文件或回到对话恢复阻止（状态机单元用例覆盖）。
- [x] 相对资源限定授权根：`dcode-asset://` 解析单元用例（根内放行、`../..` 越界拒绝、scheme/host 不符拒绝、query 忽略）+ `readRawBytes` 原始字节安全读取（二进制原样返回、越界 / 符号链接拒绝）；scheme handler 主线程回调、stop 取消不触碰 task。
- [x] `swift test`（231 用例）、`cd host && npm test`（139 用例）全绿；版本统一提升 `0.0.18`。
- [ ] 人工验收：真实项目内打开含内联脚本与本机 CSS 的 HTML → 编辑即时刷新 → 外链图片触发联网询问 → 本次允许 / 保持阻止各走一遍 → 保存后磁盘核对；越界资源（`../../` 出授权根）确认不加载。

## Out of Scope（不进入本版）

自由网页浏览（地址栏 / 前进后退）、逐条子资源联网询问、持久化联网授权、远程 URL 主导航加载、HTML 语法高亮、除 HTML 外的文本编辑、预览内容自动进入模型 Context、HTML 写回格式化、DevTools 面板。
