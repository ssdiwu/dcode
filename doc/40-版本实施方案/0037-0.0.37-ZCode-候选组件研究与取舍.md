状态：507 于 2026-10-02 确认此前十项候选全部可以加入，并授权在 1～2 个后续版本中规划、对普通 UI／UX 大量借鉴。该轮取舍已结束，按依赖分为 `0.0.38` 和 `0.0.39`；本文件保留原路径作为研究与版本路由，不再拥有待选状态或逐功能规格。

承接依据：2026-09-29 将额外十项放入研究池；2026-10-01 核对固定 ZCode 源码并形成 [27 份来源与当前能力对照](../参考文件/ZCode-组件清单与-D-Code-对照-2026-09.md)。现有 `0.0.37` 单图试验、Pi SDK `0.99.1` 和中英语言仍分别由 [0036](0036-0.0.37-任务内图像生成与产物归档产品需求.md)、[0038](0038-0.0.37-Pi-SDK-升级产品需求.md)、[0039](0039-0.0.37-中英界面与沟通语言产品需求.md)拥有；本次后续规划不追认这些版本的人工验收、源码提交或发布。

## UI／UX 借鉴与特有部分

普通导航、标题、输入、加号与搜索菜单、队列、附件、对话、文件摘要、成员／阶段、历史、对象详情、设置、空／加载／失败反馈、排版和微交互均进入借鉴范围。可核许可的共享 React 组件与 helpers（辅助函数）可以源码级适配，逐文件登记来源和许可，并在 D Code 真实路径验证；不只停留在参考截图。

保持 D Code 特有的品牌、Project／Task／Session／Agent／Artifact 事实、`/`／`@`／`$` 语义、成员创建权、系统提示词、原文／来源、Product Store、运行权限、macOS 焦点与目录／凭据边界。ZCode 的品牌、收费／闲时后台、增长、远程／Windows、私有格式和 Runtime 不纳入。精确行为只在 0040／0041 定义，本文件不复制规格。

## 开发身份与交付边界

当前实际 manifest 与已有候选仍为 `0.0.37`，因为本次只完成后续规划。开始 `0.0.38` 或 `0.0.39` 代码、生成本机候选前，须先同步对应客户端／Host、锁文件、握手与断言，并声明独立目标号校验和打包；不重现新版本实现打成旧版本号的问题。

两版都须覆盖新行为的正常、失败、冲突、重启、来源、权限、无障碍和真实窗口路径，并完成 `507-review` 收口。所有未提交改动与存量数据继续保护；没有授权提交、推送、部署或发布。规划与源码借鉴许可不等于组件已经实现，也不替代自动检查、本机候选、人工验收和正式分发。
