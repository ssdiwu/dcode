# D Code 0.0.9 打开即接管产品需求

状态：Implementation Candidate（实现候选，待人工验收）

本 PRD 冻结 `0.0.9` 的范围与验收边界；打开即接管、租约抢占与冲突重接语义以 [ADR 0018](../决策档案/0018-打开即接管与单写入所有权.md) 为准（取代 [ADR 0006](../决策档案/0006-共享观察与按需写入.md) 的默认观察立场）。`0.0.9` 同时收口两项性能工作：Host 内 ModelRuntime 单例复用（已证修复）与冷启动 / 输入路径的 os_signpost 埋点（供 Instruments 实测）。

## Problem Statement（问题陈述）

`0.0.8` dogfood 确认只读观察模式制造了系统性的二等会话状态：打开既有会话默认只读，上下文用量为空值、命令清空、构成占比不可用；冲突后被静默降级回观察。产品判断：该模式的存在是错误的，D Code 是一等公民。此外新会话每次激活都触发 `ModelRuntime.create` 全量解析模型库，冷启动 / 新建会话输入存在可感卡顿（已证部分归因，余下待埋点实测）。

## Solution（解决方案）

按 ADR 0018：`session.open` 一律可写接管（先校验目标、失败不动当前会话，再关闭当前、取租约）；D Code 实例间租约支持 force 抢占，旧属主每秒自检发现 owner 变化即以 `LEASE_STOLEN` 冲突诚实退出；静默窗口保留为防撕裂护栏（在途写入时轮询到稳定）；外部写入冲突以原生冲突卡呈现并提供"重新接管"。Host 删除只读观察全部机制与 `writeIntent` / `preserveActive` / `SESSION_READ_ONLY` / `WRITE_INTENT_REQUIRED`；ModelRuntime 按 agentDir 单例复用；`AppStart` / `ComposerTextUpdate` 加 os_signpost。

## Confirmed Constraints（已确认约束）

- Pi 会话单写入所有者边界不变；session-lease 仅是 D Code 实例间互斥，Pi CLI 写入靠指纹检测。
- 抢占只发生在 D Code 实例之间；重接只能由用户显式触发，不做自动乒乓。
- 静默窗口等待的是文件稳定，不等待用户；有限重试后如实报 `SESSION_NOT_IDLE`。
- 冲突后草稿保留、队列暂停、Run 标记未知的既有语义不变。
- App 与 Host 按版本锁同步发布（`0.0.9`）。

## Acceptance Criteria（验收标准）

### 打开即接管

- [x] 所有打开路径（侧边栏 / 搜索 / 复制 / 路径切换 / 归档 / 冲突重接）一律可写；打开期间租约目录存在，关闭后释放（Host 用例）。
- [x] 过期搜索目标（entry 缺失或摘要不符）在关闭当前会话之前被拒，当前会话不受影响（Host 用例）。
- [x] 第二个 D Code 实例打开同一会话直接抢占成功；第一个实例在冲突轮询中发现 `LEASE_STOLEN` 并以 `session.conflict` 退出，后续写入被拒（Host 用例）。
- [x] 目标文件在途变化时轮询至稳定完成接管；持续变化超时报 `SESSION_NOT_IDLE`（Host 有限重试）。
- [x] 只读机制（观察轮询、独立 ModelRuntime、降级 getState / 命令 / 构成）全部删除；Host 测试套件不再存在只读用例。

### 冲突与重接

- [x] 外部写入触发 `session.conflict`：停止写入、保留草稿、暂停队列、Run 标记未知。
- [x] Swift 呈现冲突卡，区分"外部写入"与"写入权被接管"；"重新接管"重新可写打开并清除冲突态（Swift 集成用例）。
- [x] abort 失败 / 租约释放不可校验仍保留锁并 poison 后续写入（`HOST_RESTART_REQUIRED`）（Host 用例）。

### 性能

- [x] ModelRuntime 在 Host 生命周期内单例复用；新会话激活与模型页不再重复全量解析（已证修复）。
- [x] `AppStart` 与 `ComposerTextUpdate` os_signpost 埋点；冷启动输入卡顿的实测路径与数据留待人工验收记录。
- [ ] 真实环境手测：冷启动与新建会话输入手感对比（附 Instruments signpost 数据）。

### 版本与发布

- [x] App / Host / Info.plist / build.sh 版本一致为 `0.0.9`。
- [x] `swift test`（169 用例）、`cd host && npm test`（125 用例）全绿。
- [x] `./app/build.sh` 产出 `dist/D Code.app`（0.0.9，434M，签名通过），内嵌 Host 与 App 版本核验为 `0.0.9`。
- [ ] 真实环境人工抽查：与 Pi CLI 并用一会的接管与冲突流、两个 D Code 窗口的抢占与重接、真实会话的上下文构成弹层。
