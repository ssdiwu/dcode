# D Code 0.0.37 中英界面与沟通语言产品需求

状态：507 于 2026-10-01 确认提供中文与英语两种语言，所选语言同时用于界面、新生成的子会话标题和智能体回复。本版与 [Pi SDK 升级](0038-0.0.37-Pi-SDK-升级产品需求.md)、[任务内单图生成](0036-0.0.37-任务内图像生成与产物归档产品需求.md)共同实施。当前主树为未提交实现，自动检查、候选窗口走查与 507 人工验收分别记录。

## 目标与用户路径

1. 设置 → 外观提供“显示与沟通语言”，仅支持 `中文` 与 `English`。首次使用及旧偏好缺少该字段时使用中文。选择保存在 D Code Product Store，重启后仍生效；无效值明确拒绝。
2. 保存成功后界面和 D Code 原生菜单即时采用所选语言。使用保存回包更新呈现，不能因写后重新读取失败，把已保存的选择误报为失败或重新创建操作。切换不重新建立 Task、Session，也不丢失普通草稿、附件、工作流表单、阅读位置和自定义名称。
3. 协调者和同任务成员从**下一轮运行**起按所选语言沟通，并用该语言生成新的简短子会话工作名称。语言与实际系统提示词一同固定在本轮运行依据中；正在运行的一轮不因设置改变而改写提示词。
4. 所选语言是日常沟通的默认值。本轮用户明确要求另一种回复语言时，仅该回复服从明确要求，不修改设置或新自动标题的语言；邮件、翻译、代码及其他产物按用户对产物的语言要求交付。文件名、代码标识、引用原文及用户明确提供的名称保持原样。
5. 已有任务、子会话名称、用户原文、助手历史、摘要声明与产物正文保持原文。切换语言不对历史数据做翻译写回。程序新生成的“副本”“第 N 段”等名称后缀，以及摘要来源的栏目说明，按当前语言呈现；历史内容仍可核对。
6. 导航、输入区、“＋”菜单、模型连接、设置、目标、工作流、成员概览、执行过程、来源详情、文件预览和常用产品错误使用同一份中英文界面词表。动态值与历史正文不通过界面词表自动翻译。系统文件选择器等 macOS 自有界面使用系统语言。

## 验收标准

- [x] 中英即时界面、保存与重启偏好核对通过；静态选项按当前语言读取，历史正文不通过词表翻译。
- [x] 隔离 Electron 在保存成功后制造偏好读取失败：保存结果仍明确，界面与菜单使用成功回包，不重复提交同一操作。
- [x] 受控 Provider 捕获实际协调者和独立成员进程的 SDK 请求：新一轮提示词及运行快照采用所选语言；未把受控模型返回当作真实模型语言质量验收。
- [x] 中文输入／英语设置和相反组合的运行指令、自动成员标题 schema 与显式语言例外回归通过；用户指定的名字、产物语言及历史保持原文。
- [x] 普通草稿、附件和历史正文保留；Store 测试核对复制／续接的中文及英语后缀与原名不变。
- [x] 真实 Electron 的 48 组中英、浅深色、标准／大字号、两类长标题及三档宽度核对通过；主对话按钮保持一行且文字不越出顶部栏，返回主对话与重启草稿恢复通过。
- [x] 显式产品文案及静态选项自动扫描没有缺失英文项，动态占位符保持一致；全量自动检查与独立交付审查通过。系统控件语言和真实模型输出体验仍由各自环境／人工验收确认。

## 非目标

本版不引入第三种语言，不自动翻译历史会话，不更改项目文档或自定义智能体职责正文，不将设置等同于模型能力或计费方式，也不因语言需求扩大 ZCode 候选池的实现范围。
