# D Code 0.0.37 Pi SDK 升级产品需求

状态：507 于 2026-10-01 明确要求完成 Pi SDK `0.99.1` 升级并纳入 `0.0.37`。本文件拥有该升级的产品行为与验收；同版已确认的单图生成由 [PRD 0036](0036-0.0.37-任务内图像生成与产物归档产品需求.md)负责，中英界面及沟通语言由 [PRD 0039](0039-0.0.37-中英界面与沟通语言产品需求.md)负责。ZCode 十项候选仍由 [0037](0037-0.0.37-ZCode-候选组件研究与取舍.md)记录，不能从 SDK 授权推导为全部选中；本轮不改写已有标题与历史消息。

## 问题与目标

升级前锁定的 Pi SDK `0.87.1` 缺少 GPT-6.1 Sol 的内置模型目录。升级到已指定的 `0.99.1` 时，新模型类型、工具执行上下文、模型目录请求和 OpenAI 订阅登录方式须进入 D Code 既有产品合同；用户已保存的项目、任务、会话、连接、模型选择、工具权限与结果不得因换包而失效或变成另一套产品状态。

## 用户路径与需求

1. **模型与选择**：OpenAI 与 OpenAI Codex 的可用模型目录可以识别 GPT-6.1 Sol；已有默认模型及会话选择只在仍可用时沿用，不用 SDK 的新默认值覆盖用户保存的选择。离线内置目录、在线更新、自定义供应商和重启恢复分别可核验；显示可用必须有当前连接与权限依据。
2. **连接与计费来源**：OpenAI 的 API Key 与 ChatGPT 订阅登录分别作为真实可用方式呈现，登录状态来自对应认证。旧 OpenAI Codex 连接保持身份与历史，不能静默迁移凭据或将订阅方式回退为 API Key 消耗。新认证沿用 Host 私有交互与钥匙串边界，凭据正文不进入 Product Store、公共协议、日志或模型上下文。
3. **工具与执行边界**：D Code 继续从明确授权的活动工具快照生成 Prompt Receipt，并以独立 Agent Execution Process 执行成员。SDK 新增的 MCP、codemode、分类和图像运行能力不自动成为 D Code 活动工具或产品入口；外部扩展、只读／写入权限与目录所有权沿用已有合同。
4. **连续工作与恢复**：普通输入、即时补充、排队、工具批次、停止、压缩、成员重启、报告保存、返工与独立复查保持原语义。用户提交原文、模型生效输入和证据可回查；生成或外部操作已经发生时，失败和结果未知不得被自动重放。
5. **并行准备冲突**：模型请求前，若其他成员刚刚更新 Task 事实，使准备中的摘要过期，Host 可以在有界范围内重新读取并准备本次普通输入。重试只发生于未提交的 Store 准备已回滚的边界，不重复保存用户消息或启动 Provider。事实持续变化时，明确失败并保留可继续状态。显式历史路径操作不由内部重试重新分支；冲突时恢复原当前路径、保留编辑草稿并要求重新核对路径。
6. **构建身份**：App／Host 的开发版本、锁文件与握手统一为 `0.0.37`；包内三项 SDK 均固定 `0.99.1`，生产依赖与许可完整装配。本机候选、人工验收、旧数据迁移／回退和正式发布各自记录，不由版本号推断完成。

## 验收标准

- [x] 主树与独立候选中三项 SDK 均为 `0.99.1`，App／Host 与包内版本同为 `0.0.37`；内置模型目录含 OpenAI／OpenAI Codex 的 GPT-6.1 Sol，并保留既有模型。
- [x] 在线目录更新、自定义模型、保存的选择与 Host 重启回归通过；图像／分类模型不会混入当前聊天选择器。
- [x] API Key、现有 OpenAI Codex OAuth 与新 OpenAI 订阅方式的受控状态、取消、并发、失败、保存和恢复回归保持原安全边界；不回显凭据或静默变更计费来源。本轮没有重做真实账号授权和所有模型计费验收。
- [x] 普通协调与独立成员、跨目录工具、即时补充、停止、压缩取消、报告和定向返工复查的受控公开路径通过。活动工具不出现未经选择的 SDK 新能力；真实模型收益与人工验收独立记录。
- [x] 制造摘要在 Provider 启动前变化的反例：重新准备后只有一份提交原文、一个 Session Run 和一次模型调用，回执对应最新实际采用摘要。持续变化时有界停止，模型调用和 Session Run 均为零；显式历史路径冲突不自动重试分支并保留编辑草稿。
- [x] 隔离全量 Host／客户端回归、包内 Host 启动与握手、实际包窗口和独立交付审查分别记录；真实供应商全矩阵、旧数据回退和 507 本人验收仍未成立。

## 非目标

- 不迁移到 Pi AgentHarness／Pi Durable 的产品存储，也不改变 D Code Product Store 权威。
- 不因为 SDK 提供新工具就开放 MCP、codemode、分类、生图或第二套团队入口。
- 不改写已有用户消息、子会话标题或凭据归属，不把候选编号和版本标签当作历史发布。
