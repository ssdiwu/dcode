# D Code 0.0.11 只读 Exact Git Diff 产品需求

状态：Implementation Candidate（实现候选，待人工验收）

本 PRD 冻结 `0.0.11` 的范围与验收边界；Git 事实来源、双轨诚实与只读边界以 [ADR 0020](../决策档案/0020-Git-差异事实来源与只读边界.md) 为准。

## Problem Statement（问题陈述）

变更 Tab 目前只显示 Git status 的文件级列表与 `0.0.4` 会话账本的 +N/−N 摘要；用户无法在 D Code 内核对逐文件、逐 hunk 的行级真实差异，也无法区分 staged / unstaged。

## Solution（解决方案）

Swift 侧扩展既有 Git 管道：`UnifiedDiffParser` 解析单文件 diff（hunk 头、a/b 行号、增删上下文行）；`GitDiffReader` 按需分流读取 `git diff`（未暂存）与 `git diff --cached`（已暂存）；untracked 文件以受护栏内容作新文件预览。变更 Tab 文件行可展开，呈现"已暂存 / 未暂存"两区的 hunk 级逐行渲染（+ 绿 / − 红 / 上下文，双行号），底部声明只读边界。

## Confirmed Constraints（已确认约束）

- 只读：不提供 stage / discard / commit / push；全程 `GIT_OPTIONAL_LOCKS=0`。
- 事实以 git 输出为准；与会话变更账本双轨并存、互指区分。
- 截断护栏：单文件 > 512KB 或 > 3000 行诚实截断；二进制标注；untracked 读取沿用授权根 / 2MB / UTF-8 约束。
- Host 与协议零改动。
