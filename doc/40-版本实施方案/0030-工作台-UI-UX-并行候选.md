## 第一批：新任务与主题

1. 新任务由真实草稿入口进入，品牌、标题、输入卡与归属选择在主工作区居中编排；使用当前 C-A 品牌。已有任务即便没有消息也不进入创造背景。
2. 背景仅用于新建任务草稿，使用精确注册的 StructureFlowCollection：`structure-flow`、`speed=1`、`pointSize=.08`、`opacity=.4`、`maskStart=.2`、`maskSolid=.5`。五份源码保持原文和 SHA-256。
3. 深色暗底白粒子、浅色浅底黑粒子；浅色仅反相背景外层，内容不反相。灵感、设置、已有对话不创建该 WebGL 实例。
4. 页面隐藏、退出新任务释放场景；返回重新挂载。减少动态效果、没有 WebGL、上下文丢失或场景加载失败时使用静态背景，输入/草稿/发送照常工作，不用另一种仿制粒子替代。
5. ⌘N、首次提交、输入法确认、Shift+Enter、附件与真实模型选择沿用现有流程；返回之前任务不清空未提交草稿。只有真实创建成功才进入任务。
6. 外观设置沿用 `clientPreferences` 与 Electron `nativeTheme`。颜色扩散以操作按钮当前矩形中心为原点，键盘同样成立；持久化与桌面主题生效后捕获新画面。减少动态效果或不支持 View Transition 时直接切换；保存失败仍显示错误。

## 第二批：真实入口与结果反馈

- 整理已有输入控件的顺序、标签、项目/上下文 chip，不引入原型假按钮；`@` 仅表示本任务已创建成员，`/` 复用已启用技能与命令。
- 真实加载出现时提供稳定占位，成功后替换内容，避免人为等待；复制成功在原处反馈，失败如实显示；保留草稿与阅读位置。

## 第三批：统一动效

- 建立少量共享时长和曲线，覆盖按压、展开、切页及已有文件标签与任务浮层；沿用已有 motion 依赖及几何。
- 流式反馈只作用于本次新增内容，历史不重播。运行、完成、失败、停止来自真实状态，失败/停止不能显示成功勾。过程默认收起，不制造假推理或第二套主导航。
- 键盘焦点、减少动态效果、长消息性能和等宽数字适用范围同时验证。

## 独立能力批次：模型安全连接

507 已确认需要在“未连接”旁直接完成 Pi SDK 支持的 OAuth 或 API 连接；本批与技能菜单修复分别验证和提交。

- 连接方法来自固定 Pi SDK 的实际 Provider 合同。OpenAI 提供 API 密钥连接，OpenAI Codex 提供 ChatGPT 登录；没有 OAuth 的供应商不能出现虚构 OAuth 按钮。自定义供应商继续保留安全环境引用，也能使用核心管理的密钥输入。
- 在供应商附近展示未连接、等待安全窗口、等待浏览器、保存中、已配置、已连接、需重新登录、取消和失败重试。API 密钥保存不等于联网验证，明确显示“已配置，首次请求时验证”；OAuth 登录成功表示授权交换及安全保存完成，不保证所有模型权限。
- Host 独占机密输入、浏览器登录和钥匙串；应用页面、桌面壳、公共协议、产品数据、诊断及会话不接触密钥、令牌或 OAuth 回调值。SDK 负责登录和令牌更新协议，D Code 负责安全引用与连接状态。
- 每个 Provider 的受管凭据更新与断开互斥，令牌刷新在最新凭据上进行。取消及超过 10 分钟流程期限的回调不保存，重复流程不重复执行；保存已经开始时明确显示保存中。登录或存储失败不显示连接成功。
- 重启从安全引用和钥匙串恢复可用状态，外部 Pi 凭据只读；断开只删除 D Code 在当前数据根管理的连接，不删除外部 Pi 认证。若还存在外部来源，明确显示其仍可用。已发出的请求继续返回；之后的请求按最新凭据判断可用性，不伪装中断已经发送的请求。
- 成功连接或断开后更新模型选择、可用性和既有路由；历史模型选择和任务记录不被删除。受管 OAuth 接近到期显示待更新，由 SDK 在下一次使用时续期；实际续期失败才需要重新连接。只读外部 OAuth 到期前 5 分钟退出可用候选，其他有效供应商保持可用。

验收：使用受控 Provider、隔离凭据适配器及专用钥匙串命名空间的假值覆盖成功、取消、失败、过期、迟到回调、重复开始、保存失败、重启、并发更新、断开范围与敏感信息不进入公共输出；在独立 Electron 窗口验证真实页面入口与状态。真实账号登录由 507 在安全输入窗口完成，自动验证不冒充真实账号人工验收。
