# 版本实施方案

本目录保存已经确认、用于指导当前版本交付与验收的 PRD 和专项规格，也是发布、实现候选、本地回归基线、人工验收与持续回归状态的唯一文档索引。具体测试与人工证据保留在对应 PRD 的 Verification Record（验证记录）中，其他 README 只链接本页，不复制动态状态。文档完成后只要仍是有效验收基准，就继续保留在本目录；仅在被取代、放弃或只供追溯时归档。

`0.0.5` 已形成公开源码标签 `v0.0.5`；自动测试、App 构建、Composer 焦点与左右栏宽度的定向 App 验收通过，真实 Pi 连续入队、强制终止时序与 VoiceOver 等人工验收仍未完成。`0.0.6` 的 Activity View（活动视图）、Host Run State（运行状态）、完成关注态与 Interaction Dock（交互坞）已经进入 Active Implementation（实现中）：App / Host 开发版本、自动测试与本机 App bundle 构建已成立，新会话草稿也已补齐创建前 Pi `enabledModels` 范围与默认模型读取、统一模型 / 推理强度 / 速度菜单、标准速度默认值、支持资格门禁、模型左侧上下文剩余量圆环与首条 Prompt 前运行设置应用；较早同版本候选的默认导航 ↔ Activity 切换只读 smoke 通过，当前重建 bundle 的运行设置菜单与首条真实 Prompt 尚待人工验收。真实 Run、完成蓝点、停止 / 重试时序与完整无障碍人工验收仍须独立成立。完整 Model Settings 已前移为 `0.0.7`。`0.0.6 → 0.0.18+ → 0.1.0` 的已确认顺序、逐版差异和“连续自构建后才晋升”的门禁见[版本界面演进](../20-产品与交互/原型/版本演进/README.md)。该路线允许按真实 dogfood 缺口继续增加 `0.0.x`；`0.0.7` 及以后在进入本目录并形成独立 PRD 前仍不是冻结交付范围。
