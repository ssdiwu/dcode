# D Code 0.0.14 主页落地 Composer 与界面收口产品需求

状态：Published Source Tag（公开源码标签 `v0.0.14`；自动门禁与 App bundle 记录已成立，完整视觉与无障碍人工验收仍待完成）

本 PRD 冻结 `0.0.14` 的范围与验收边界；动作权限以 [ADR 0023](../决策档案/0023-固定完全访问与动作级权限闸门移除.md) 为准，界面语义以 [`0002-D-Code-原生界面设计系统`](../10-架构与运行/0002-D-Code-原生界面设计系统.md) 为准。

## Problem Statement（问题陈述）

实机走查与竞品对照发现质量分布不均匀：主页是"空态图标 + 两个按钮"，必须点击"新建会话"才能开始且新建后输入框不聚焦；点击会话到内容呈现之间数秒无反馈；发送按钮 36pt 实心盘独享一套几何；模型 chip 字号超过次级信息地位；`DesignSystem.swift` 没有字号缩放机制；自构建设置页与相邻页视觉断层；0.0.10 权限闸门对唯一使用者形成高频打断；pi-di18n 等扩展的 TUI 状态提示（`lang:…`）在每次打开会话时弹为顶部横幅。

## Solution（解决方案）

主页改为落地即可打字的会话前草稿：无会话打开时自动恢复或创建新会话草稿（默认用户目录），与 Composer 共用同一组件、启动即聚焦；占位符为 `交给 D Code 一项工作，/ 使用命令`（设计系统 3.4 hint 档 + 7.6 文案预算，只教已实现能力）；作用域托盘承载 Source Folder chip 与只读 Git 分支 chip；输入框下方保留 2–3 条最近会话安静行。配套收口：会话打开加载态与行级即时选中、⌘N 与侧栏动词行快捷键常显、会话行时间戳右对齐常显（悬停由动作按钮覆盖尾部槽位）、发送按钮收进 4.1 图标动作几何（容器常在、权重分档）、模型 chip 降为 caption、设置 > 外观新增"界面字号"档位（经 Dynamic Type 整体缩放）、自构建设置页补齐页标题与卡片容器、`/` 命令面板补键盘导航（↑↓/Esc/回车选中）、新增 设置 > Host 诊断 只读日志页，并将 `lang:` / `i18n:` 前缀的扩展状态提示从横幅改入该日志、会话轮次折叠态改为逐步安静摘要（相邻同类合并，如「探索 · 3 文件」「已编辑 文件名 目录 +1 −1」「思考过程 持续了 N 秒」）。权限按 ADR 0023 最终形态整体移除闸门机制（固定完全访问，无切换）。

## Confirmed Constraints（已确认约束）

- 延迟创建机制不变：首次发送非空正文才创建真实 Pi Session；该实现细节不在界面上解说。
- 不做问候语、时间感知文案、建议 prompt / 模板卡片。
- 占位符只教已经实现的快捷输入：`@` 插入上下文能力不在本版范围，也不在占位符中预告。
- 权限固定完全访问（ADR 0023）：bash / 写入 / 自定义工具静默执行；闸门、授权表、审计、`permission.*` 协议与权限 UI 全部移除，无模式切换。
- 不动 `AppModel.swift` 架构拆分与 4.4 节性能重构；魔数清理只限触及部分。
- 界面字号只提供紧凑 / 标准 / 大三档，不做自由数值输入；无障碍特大档不参与缩放。

## Acceptance Criteria（验收标准）

- [x] 主页：无会话时自动恢复或创建草稿并聚焦 Composer；作用域托盘默认 `~`、可换目录（正文保留、模型重载）、Git 仓库目录显示只读分支 chip；最近会话行点击即继续；Host 未就绪时显示连接状态而非假输入框。
- [x] 聚焦：App 启动、新建会话、打开会话、从设置返回时输入框自动获得键盘焦点（渲染冒烟）。
- [x] 加载态：点击会话后主画布立即出现 spinner 占位，会话行同步进入选中态，打开失败回退选择。
- [x] ⌘N 全局快捷键 + 侧栏动词行常显快捷键；会话行时间戳右对齐常显（设计系统 7.1 同步修订）。
- [x] 发送按钮 28/32 几何，容器常在、权重分档（可发送 accent 填充 / 暂不可发送中性极低填充 + 次级色 glyph，禁用不被系统二次变暗）；模型 chip caption 字号。占位符走 hint 档并与真实正文共用布局几何（离屏渲染用例锁定各字号档对齐与墨色档位、发送按钮容器与禁用档）。
- [x] 界面字号：紧凑/标准/大三档经 Dynamic Type 偏移实现，标准档跟随系统，封顶常规层级（单元用例覆盖档位换算与回退）。
- [x] 权限：`dcode-permission` 闸门、授权表 / 审计持久化、`permission.*` 协议方法、`permissionGate` 能力位、Swift 权限卡 / chip / 设置页全部移除且无残留引用；两侧测试套件移除对应用例后全绿。
- [x] 自构建设置页使用统一页标题 + 卡片容器；命令面板 ↑↓/Esc/回车键盘导航。
- [x] Host 诊断：stderr 与扩展旁路输出入 200 条环形只读日志并有设置页；`lang:` / `i18n:` 前缀的扩展状态提示（含 warning 级别）不弹横幅、普通扩展通知仍横幅（集成用例）。
- [x] 轮次逐步摘要：折叠态按步骤显示安静状态行——相邻同类合并（探索按去重文件数、命令按次数、思考按段与时长）、编辑 / 创建按目标文件聚合并显示目录与 +N −M / 行数、失败步骤行内标注；行数封顶 8 行并以「另有 N 步」收口；展开仍为完整思考与工具过程（单元用例覆盖合并、失败、截断与思考时长）。
- [x] `swift test`（189 用例）、`cd host && npm test`（125 用例）全绿；版本 0.0.14。
- [x] `./app/build.sh` 产出 `dist/D Code.app`（0.0.14，435M，签名通过），内嵌 Host 与 App 版本核验为 `0.0.14`。
- [ ] 人工验收：对照设计系统第 9 节验收矩阵走查新主页 Composer（六态、深浅色、Tab 顺序、VoiceOver），并实机确认启动即聚焦、会话打开加载态、⌘N、字号三档、`lang:` 提示不再弹横幅。
