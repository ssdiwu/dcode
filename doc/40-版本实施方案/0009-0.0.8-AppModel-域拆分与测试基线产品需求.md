# D Code 0.0.8 AppModel 域拆分与测试基线产品需求

状态：Implementation Candidate（实现候选，待人工验收）

本 PRD 冻结 `0.0.8` 的工程内构范围与验收边界；AppModel 域拆分、`HostProviding` 注入与渲染测试策略以 [ADR 0016](../决策档案/0016-AppModel-域拆分与宿主注入测试边界.md) 为准。`0.0.8` 不新增用户可见产品能力，不改变 Pi Session 权威、协议版本语义与任何运行时行为；`0.0.7` 的全部用户可见范围继续以 [0.0.7 PRD](0008-0.0.7-模型设置与回复运行信息产品需求.md) 为准。

## Problem Statement（问题陈述）

`0.0.7` 收口时 AppModel 约为 4,500 行、183 个方法的单一状态容器，`handle(_:)` 单函数超过 200 行；搜索、活动、模型设置、后续队列与转录流式状态无法按域辨认，新增功能没有明确落点。同时 UI 状态机几乎不存在自动回归：宿主客户端直接 spawn Node 进程，测试必须依赖真实 Pi 环境，导致 `0.0.5`–`0.0.7` 的关键收口（失败清理、进程退出、Run 状态、认证事件流）长期只靠人工手测。

## Solution（解决方案）

按 ADR 0016 拆分：领域状态迁入 `SearchModel`、`ActivityModel`、`ModelSettingsState`、`FollowUpModel` 四个 `@Observable` 子模型，视图改用嵌套路径访问；事件分发拆为四个事件族扩展文件，`handle(_:)` 只保留路由。宿主依赖收敛为 `HostProviding` 协议并开放 init 注入，测试用 `FakeHostClient` 与临时目录 store 驱动完整状态机。渲染层采用 ViewInspector（简单视图）+ `NSHostingView` 真实宿主（主界面）混合冒烟。全部迁移坚持纯搬移，行为零变化，由既有 141 个用例与新增测试共同守护。

## Confirmed Constraints（已确认约束）

- 不改变任何用户可见行为、协议方法、事件语义与存储格式；拆分前后二进制行为等价。
- 不触碰真实 `~/.pi/agent`、用户 `Library/Application Support/D Code` 与真实凭据；全部测试使用临时目录与脚本化假宿主。
- ViewInspector 为测试目标专用依赖（MIT，精确锁 0.10.3），不进入 `D Code.app` bundle；其能力边界（`@Observable` 环境注入、复杂视图树崩溃）如实记录，不扩大使用面。
- 转录、流式、Prompt / Follow-up 结算时序本轮不拆，仍留在 AppModel 本体。
- 原则上被跨文件引用的成员从 `private` 放开为模块内可见，不引入公共 API。

## Acceptance Criteria（验收标准）

### 状态拆分

- [x] `SearchModel`、`ActivityModel`、`ModelSettingsState`、`FollowUpModel` 各自拥有本域状态与叶子操作；AppModel 持有子模型并保留跨域协调职责。
- [x] 全部视图经 `model.search.*` 等嵌套路径读写域状态；`@Bindable` 绑定路径不因拆分失效。
- [x] `handle(_:)` 收缩为事件族路由；会话 / Plan、扩展、模型认证、宿主生命周期四组 case 原样迁移到扩展文件，事件行为不变。

### 可测性

- [x] `HostProviding` 协议覆盖 AppModel 全部宿主调用面；`PiHostClient` 为唯一生产实现；client factory 可从 init 注入。
- [x] `FakeHostClient` 支持按 method 脚本化响应、请求记录与主动事件注入；`HostTestHarness` 将全部本地 store 指向临时目录。
- [x] 集成测试覆盖：握手成功 / 失败清理、意外与预期进程退出、Run 状态与完成注意力记录、搜索索引状态、模型认证事件流、重启要求保留观察。
- [x] 渲染冒烟覆盖：RootView 空态 / 打开会话态、ConversationView 轮次 + 流式、Composer 运行中排队态、ModelSettingsView 快照态、UserHomeView 与 ConversationRoundRail 结构断言。
- [x] `THIRD_PARTY_NOTICES.md` 登记 ViewInspector 及其不进入 bundle 的边界。

### 版本与发布

- [x] App / Host / Info.plist / build.sh 版本一致提升为 `0.0.8`，握手版本校验两侧同步。
- [x] `swift test`（156 用例）、`cd host && npm test`（130 用例）全绿。
- [x] `./app/build.sh` 产出 `dist/D Code.app`（0.0.8，433M，签名通过），内嵌 Host 版本核验为 `0.0.8`。
- [ ] 真实环境人工抽查：正常启动、打开真实会话、发送一轮、模型页只读视图与 `0.0.7` 行为一致。
