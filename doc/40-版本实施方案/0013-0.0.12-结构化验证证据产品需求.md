# D Code 0.0.12 结构化验证证据产品需求

状态：Published Source Tag（公开源码标签 `v0.0.12`；自动门禁与 App bundle 记录已成立，人工验收仍待完成）

本 PRD 冻结 `0.0.12` 的范围与验收边界；证据身份、账本与非门禁边界以 [ADR 0021](../决策档案/0021-验证证据身份与账本边界.md) 为准。

## Problem Statement（问题陈述）

模型常以文案宣称"已验证"，但 D Code 内没有可复核的执行记录：命令、退出状态、耗时、当时的 revision 与环境无处核对，用户只能选择相信或离开 D Code 查证。

## Solution（解决方案）

Swift 侧从既有 `tool_execution_start/end` 转发事实组装证据账本：bash 执行落 `verification-evidence-v1.json`（命令、退出推导三态、起止与时长、cwd、模型），落账后异步补 `git rev-parse HEAD`（按目录缓存 5 分钟，可缺席）；会话检查器新增"运行证据"区（徽标 + 耗时 + revision 短 SHA，展开看 Run / 时间 / 环境 / 完整 revision），底部声明非门禁；覆盖范围按 runId 联结会话变更账本。

## Confirmed Constraints（已确认约束）

- 证据只来自 Host 转发的真实工具执行；Agent 文案不入账。
- 退出为推导三态（ok / failure(code) / unknown）；revision 异步补全、可缺席。
- `0.0.12` 只记 bash；不新增覆盖采集；不做自动发布或合并门禁。
- Host 与协议零改动。

## Acceptance Criteria（验收标准）

- [x] UI：会话检查器"运行证据"区渲染成功 / 失败 / 未知三态与展开详情（渲染冒烟）。
