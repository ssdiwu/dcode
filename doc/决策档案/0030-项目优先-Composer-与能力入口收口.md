# 项目优先 Composer 与能力入口收口

状态：Partially Superseded（Project 与能力范围继续有效；模型入口与 `+` 容器形态由 ADR 0033 修正）

主页 Composer 的下挂条只显示当前 Project 名称，不显示目录、分支或“此项工作归属”；它以独立阴影承托主输入面。`0.0.25` 曾把去掉 CPU 图标与外露下拉 glyph 错误实现为删除模型入口；当前控制行与菜单容器以 [ADR 0033](0033-Composer-模型选择与原生能力菜单边界.md) 为准。

`+` 的能力范围继续是添加图片或文件、Skill、命令、目标、计划。目标与计划按真实已加载能力执行，但产品标签不附带来源名。插件、扩展、本机资源和网页预览不进入该菜单；当前容器改为 ADR 0033 的紧凑原生 Menu。

该收口不恢复权限模式：D Code 继续固定完全访问，界面不出现授权下拉、权限卡或权限审计。
