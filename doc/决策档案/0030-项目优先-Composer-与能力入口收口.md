# 项目优先 Composer 与能力入口收口

状态：Partially Superseded（Project 归属与真实能力边界继续有效；模型入口由 ADR 0033 修正，`+` 的历史容器决定随 ADR 0044 转向 Electron + React 后失效，`0.0.36` 新面板由 PRD 0033 定义。）

主页 Composer 的下挂条只显示当前 Project 名称，不显示目录、分支或“此项工作归属”；它以独立阴影承托主输入面。`0.0.25` 曾把去掉 CPU 图标与外露下拉 glyph 错误实现为删除模型入口；模型选择的控制语义仍以 [ADR 0033](0033-Composer-模型选择与原生能力菜单边界.md) 为准。当前客户端容器遵守 [ADR 0044](0044-Web客户端与桌面壳技术栈边界.md)，后续“＋”面板行为由 [PRD 0033](../40-版本实施方案/0033-0.0.36-协作过程可视化与工作台质感产品需求.md) 定义。

历史 `+` 能力范围为添加图片或文件、Skill、命令、目标、计划，前提是对应能力真实可用；这不证明当前客户端已接通目标或计划。当前容器与 `0.0.36` 的目标层级分别按实际 Electron 实现和 PRD 0033 核对；插件配置、市场、本机资源管理和网页预览不因菜单视觉变化进入一次性调用目录。

该收口不恢复权限模式：D Code 继续固定完全访问，界面不出现授权下拉、权限卡或权限审计。
