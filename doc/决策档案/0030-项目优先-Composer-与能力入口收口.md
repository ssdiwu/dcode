# 项目优先 Composer 与能力入口收口

状态：Accepted（取代 ADR 0028 中“`+` 仅为附件、资源只经 `/` 触达”的输入入口决定；图片附件与 `/` 面板的其余数据边界继续有效）

主页 Composer 的下挂条只显示当前 Project 名称，不显示目录、分支或“此项工作归属”；它以独立阴影承托主输入面。一级控制行只保留 `+`、推理强度和发送。模型名、CPU 图标与模型下拉不在 Composer 显示，模型设置继续属于设置页。

`+` 打开直接的工作操作菜单：添加图片、添加文件、Skill、命令、目标、计划。目标与计划按真实已加载能力执行，但产品标签不附带来源名。插件、扩展、本机资源和网页预览不进入该菜单；设置中的资源管理与 Workspace HTML 预览仍保留在各自原有上下文。

该收口不恢复权限模式：D Code 继续固定完全访问，界面不出现授权下拉、权限卡或权限审计。
