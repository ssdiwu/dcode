# 自迭代候选来源快照与本机分发边界

状态：Accepted（扩展 ADR 0022；约束 `0.0.26` 及后续 Self-build）

Self-build Candidate 必须对应一个显式、已验证的 D Code Source Checkout。源码根优先从用户保存选择、当前 D Code Project 或 App bundle / 当前进程位置的受限祖先发现中得到；没有合法结果时停止并要求选择，不保留个人绝对路径作为产品默认值。

自迭代的真实输入通常是未提交工作树，因此 Self-build 可以显式打开 `PI_DCODE_ALLOW_DIRTY_BUILD=1`，但产物必须在候选清单和界面中标记为 Local-only，不得进入发布语义。普通发布构建继续要求干净工作树。

候选构建前必须运行当前项目定义的 Swift 与 Host 完整回归。测试通过后创建不含源码正文的 Candidate Manifest：Git revision、dirty 状态、变更文件数量、工作树 digest、测试命令结果与生成时间。清单在签名前进入 bundle；构建完成后再次计算来源 digest，源码变化则废弃本次候选。候选校验同时检查清单、自动门禁、签名和 App / Host 版本。

Candidate Manifest 是来源与自动验证证据，不是 commit、人工验收或发布证明。重启仍需用户显式确认，原生界面与真实 Pi 行为仍由人工验收；Sol 或任何模型的回答都不能替代这些证据。
