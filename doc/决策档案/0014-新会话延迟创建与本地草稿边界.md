# 新会话延迟创建与本地草稿边界

状态：Accepted（已接受；约束 `0.0.5` 及后续版本）

## Context（背景）

此前点击“新建会话”会立即调用 Host `session.create`，把只有 Header 与 D Code 来源标记的空 Pi Session 发布到 `~/.pi/agent`，随后才打开 Composer。用户只是进入空白输入页、没有输入或直接离开，也会在 Recent 留下真实会话；这把导航动作误当成了会话事实，并迫使用户事后清理空对象。

[ADR 0007](0007-会话可见性与-D-Code-创建来源.md)已经固定 Host 的创建提交语义：一旦初始文档原子发布，稳定 Session ID 与来源标记就成为真实 Pi 事实，后续打开失败也不能伪装成“没有创建”。因此本问题不能通过“先创建、离开时自动删除”解决；自动删除既制造不必要写入，也会把正常的创建提交与可恢复废纸篓混为一谈。

## Decision（决定）

1. “新建会话”首先只进入 D Code 的 Pre-session Draft（会话前草稿）页面。该草稿只有规范工作目录和输入正文，没有 Pi Session ID、JSONL、来源标记、Session Lease、Recent / Project / Search 身份，也不会调用 `session.create` 或 `session.open`。
2. 空白或只有空白字符的会话前草稿不写入本机资料；用户离开页面、取消或退出 App 后直接消失。非空正文复用 D Code 的原子草稿资料保存，在同一 App 内离开后可再次从“新建会话”恢复，重启后也可恢复；它仍不是 Pi 消息或 Session。
3. D Code 同时只保留一个尚未发送的会话前草稿。已有非空草稿时再次从其他目录执行“新建会话”，优先恢复原草稿并明确提示；用户发送或显式取消后，才开始另一个目录的新草稿。
4. 用户首次提交非空正文时，App 才调用 Host `session.create`。Host 成功发布初始文档的时刻仍是 ADR 0007 定义的 Pi 创建提交点；App 随即把对象放入 Recent、将正文从会话前草稿转移到该稳定 Session / root Path 的普通草稿，再通过独立的 writable `session.open` 与 `session.prompt` 发送。
5. `session.create` 失败时不产生 Pi Session，原会话前草稿保持可编辑、可重试。创建已经提交但打开或首次 Prompt 失败时，不删除或隐匿真实 Pi Session；它继续出现在 Recent，正文作为该 Session 的未发送草稿保留，产品明确说明“会话已创建，但首次消息尚未发送”。
6. App 不以自动创建后自动移入废纸篓模拟延迟创建。[ADR 0009](0009-空会话可恢复清理边界.md)继续处理旧版本遗留、首次提交后打开失败或其他真实原因产生的空 D Code Session，但不是普通“新建会话”导航的默认路径。
7. 会话前草稿不支持 Session Path、Follow-up Queue、模型 / 思考强度 / 极速设置、文件或资源附件；这些能力只有稳定 Pi Session 建立并成功打开后才可用。首次提交只接受与普通直接发送相同的非空文本边界。

## Consequences（影响）

- 单纯点击“新建会话”不再污染 Pi 会话目录、Recent、Project 或 Search；空白页面不需要清理操作。
- 首次发送包含两个可区分的提交点：Pi 初始文档创建提交，以及首条用户消息持久化。创建成功不再被错误地解释为消息已经发送。
- 非空输入在创建前由 D Code 草稿资料拥有，创建后转交稳定 Session / Path 草稿；Pi 仍独占真实 Session 与消息事实。
- Host `session.create` 的原子发布、来源标记和失败恢复合同保持不变；改变的是 App 何时调用它，而不是降低 Host 的创建可靠性。

## Rejected Alternatives（未采用方案）

- **点击时立即创建，离开空白页后自动删除**：产生无意义写入与可见性抖动，并把导航取消变成文件删除流程。
- **点击时立即创建但只从 Recent 隐藏**：Pi 目录仍遗留真实 Session，且形成界面与底层事实不一致的幽灵对象。
- **直到首条 Prompt 持久化后才发布 Session**：要求把 Pi Runtime、Session 文件发布与 Prompt 执行合并为新的跨阶段事务；当前没有必要，也会破坏既有 Host 创建提交边界。用户首次执行发送后创建真实 Session 是诚实且足够的提交时机。
- **创建或打开失败后回滚已发布 Session**：违反 append-only Pi 历史与 ADR 0007 的真实提交语义，且可能掩盖用户可恢复的草稿。
