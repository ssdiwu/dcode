# Pi 会话作为唯一权威

`D Code` 以现有 Pi 会话作为命令行与桌面端共享的唯一历史和恢复权威，不建立独立的桌面会话数据库。桌面端可以维护可重建的搜索、缩略图或索引缓存，但持久消息、模型上下文、扩展状态和结构化产物必须回到同一 Pi 会话或由该会话稳定引用。这样才能让用户关闭一个客户端后在另一个客户端继续同一工作；代价是必须执行空闲态单写入所有权交接，不能允许两个客户端静默并发续写，也不承诺迁移正在生成或执行中的操作。

D Code Project 与 Source Folder 归属属于桌面端自有组织元数据，不构成会话历史；两者与 Pi Session 的权威分界见 [D Code Project 与 Pi 会话分离](0004-D-Code-Project-与-Pi-会话分离.md)。
