## 状态所有权核对

固定版本的普通AgentSession与Durable Harness是两种执行入口，不是同一次运行的双写组合。D Code产品任务也不等于Durable Task；存储独占不决定每会话必须一个进程。

原组合的关键缺口是：virtual引用不等已选物理目标，direct没有会话路由state，retry可能重新prepare。后续适配必须在原执行/提交所有者下证明身份、计划与恢复，不能用最近回调或本地计数冒充持久关联。公开HookApi和memo的实际形状曾多次被报告误述，原纠正保存在固定Git历史，不能恢复成新接口设计。

固定主源：[Durable](https://github.com/earendil-works/pi/blob/a13d35a742c6ef8462812a28fbe1d8c8b7431c32/packages/durable/README.md)、[虚拟模型](https://github.com/earendil-works/pi/blob/a13d35a742c6ef8462812a28fbe1d8c8b7431c32/packages/coding-agent/docs/virtual-models.md)。现行接线由两篇Pi合同承接，不按旧缺口重复派修。
