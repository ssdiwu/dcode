# 扩展工具内单次主动模型

本片接收 Pi 1.0 的有限单次模型请求：扩展工具在原 Durable 任务下创建模型子任务，结果交回原工具和后续请求，不另建助手、输入或历史。已经确认的费用在工具报错、嵌套调用、暂停或关闭后仍恰好计入原工具；没有最终响应时保持未知，不推算真实账单。现行行为见[开发任务路径](../../../spec/开发任务路径.md)。

## 实际失败与复验

旧实现曾没有发出内部请求、遗漏费用来源，处理模型等待时又形成自等待。嵌套结果和响应后错误、暂停／关闭的费用丢失均有原实现失败与修后证据。恢复专项还发现：只读实例关闭会误补账，暂停维护失败后又丢失后续关闭的重试资格。修后连续只读关闭不消费费用，明确继续才按原子任务一次收口，也不重发未知请求。

两次早期完整运行失败必须保留：首次包括技能与搜索的八秒超时及存储旁文件损坏，遗留监听的信号清理不是其中第三条失败；第二次是复制临时文件时消失的准备错误。观察改用自有正式存储字节副本，不再打开活动写入目录；副本不等原子数据库快照，两个旧超时没有唯一根因结论。一次证据记录器冲突丢失原始输出与独立出口，也不计通过。
