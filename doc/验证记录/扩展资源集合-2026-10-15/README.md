# 扩展资源集合与普通客户端消费

本片接收 Pi 1.0 普通扩展的唯一资源集合：技能和模板来自同一次公开加载结果，不重复拼目录或绕过筛选。声明失败、可选缺席与合法空集合分开；实际路径始终受原授权根限制。技能目录仅给描述，正文经过真实读取后才进入下一请求；应用和项目同名模板保持已确认的应用优先。

## 当前证据及失败资格

旧实现曾在首次请求重复技能描述、在同名模板时发错正文，均有目标失败与修复证据。两版候选虽完整检查通过，独立审查仍发现显式 Markdown 技能声明被静默丢弃、合法应用根被误拒，以及包内文件链接漏审，因而没有接受。修复新增检查时，又误拒原 SDK 支持的带字节序标记包清单；该兼容反例也保留。最终校验仍只消费原加载结果，不扩大目录、恢复被排除资源或把普通说明文件当坏技能。

第三轮完整运行出现两项失败、三项取消，后续门未跑。系统记录同段包含睡眠和唤醒，墙钟与单调时间差异明显，但只是相关性，不能认定唯一原因。相同字节与原期限下，相关六条、完整运行与完整界面之后通过，旧失败不回填。

## 桌面动作与恢复判别

三条普通隐藏路径实际完成配置、绑定和启用：描述一次、正文没有自动注入，工具真实读取的正文进入紧邻请求。暂停、关闭、只读重开和明确继续保持原输入与工具身份，已完成作用不重放；成功读取计数不等所有失败尝试，截图不等人工接受。
