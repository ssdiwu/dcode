## 实际改动

- `launchApp` 默认注入 E2E 隐藏标识；主进程仅在该模式下以 `show: false`、`focusable: false` 建窗，macOS 使用 accessory 激活策略。普通客户端仍按正常窗口配置启动。
- 隐藏测试保持绘制和计时，避免后台节流形成假超时；隐藏启动失败记 stderr 并退出，不弹系统错误框。显式可见验收有独立开关，失败不自动打开窗口。
- 同一会话的中文／英文 × 13／14px 滚动检查从四次启动改为一次启动、四组连续操作，结束后统一收束隔离进程。未将所有用例强行共用产品状态，真正的关闭／重开场景仍保留隔离。
- 暂停后重试用例原来全页寻找“已接收”，两条不同消息都显示该状态时产生严格定位冲突；现定位本次重试的消息行，并核对同一 operationId 只有一条 accepted 记录，保留原文与身份要求。
