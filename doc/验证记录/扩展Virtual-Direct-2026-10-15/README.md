# 普通扩展 virtual direct

本片接收 Pi 1.0 普通扩展工厂登记虚拟模型后，由原工具发起单次直接调用的路径。宿主确认登记，再重新取得正式物理模型并核认证、能力、容量和请求准入；扩展不能传入任意端点或凭据。调用不推进会话路由状态、不改变当前选择，也不新增输入或助手历史。

## 已发生的验证与失败资格

旧纯选路回调可先修改 SDK 本地工具集合，即使稍后拒绝发布仍会污染后续调用。真实反例后，改为在公开运行检查处、写入之前拒绝，保留原失效检查，不事后手工回滚。未发出请求的错误还曾缺必需用量字段而产生无效累计，现只对确实未发请求返回完整零用量，不据此猜未知服务商账单。

暂停与关闭中，部分失败来自测试把执行检查点当作完成状态，或误要求尚未发出的内部请求已经停泊，不能称产品选路反例。取消证据分开保留：关闭后释放测试门仅是放行尝试；只有原工具仍活动、单次模型已取消时，才实际观察到选路回调晚返，并确认它没有发物理请求。两者不能互相代替。
