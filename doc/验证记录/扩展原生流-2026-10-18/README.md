## 桌面可见入口

507解锁后，从正常桌面入口实际检查首页、空草稿、缺模型时禁发、外观及扩展设置往返，没有改开关、凭据或发送模型输入，再用原生退出并从同一入口重开。首次记录缺少退出进程关联，独立审查提出后另做完整周期，关联截图来源、时间及精确进程存在与消失。启动器退出成功不等于取得分离子进程的数字退出码，机器截图也不等507人工接受。

## 原失败与最终门槛

原生流最初没有实际增量消费者；兼容拒绝还暴露“未发出”错误缺完整用量，导致关闭费用对账失败。修后返回完整的未发出结果。部分桌面失败发生在末尾读取测试对端未记录的参数，不能叫产品失败，也不能因前段已经走完就算整条通过。
