## 实现与目标路径

普通 custom/preset 后端组合公开 ModelRuntime、Durable 与 read/write/edit/bash，没有另建 AgentSession 循环、输入队列或历史。主会话沿既有任务归属取得项目范围；成员无文件范围时不加载项目上下文或启用文件工具。项目指令和显式项目技能在已授权提交／明确继续之前从原绑定目录加载，不把指令文件当执行授权。

已有运行只读打开保留正式 cwd、模型及历史。首次发送的新对象可建立记录；首次建立关联须在正式提交前保存，保存明确失败可沿同对象、同 operationId 重试。已有运行记录缺失或目录归属冲突不能重建空根。每次已授权发送／继续才应用当前合法未来模型；旧单模型 Auto 入口从已保存配置取新 id，显式选择、等待、hold 与曾配置后清空不走该兼容回退，SDK 边界仍核完整能力、额度、认证和相位条件。

受控模型只发真实工具调用，工具实际读取、写入、修改与执行隔离项目中的测试。真实数字出口、工具正文和差异来自正式工具结果，进入时间线及原检查器；bash 前后文本采样有文件数、容量及排除范围，不能证明并发变化的作者归属。公开 diff 的补丁仅用于呈现，不借 Git HEAD 补造原文。
