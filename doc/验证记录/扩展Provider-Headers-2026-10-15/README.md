## 关键失败与修复

已确认的主要缺口是当次准入改选后丢失最终来源的公开头、一个客户端冲突截断其余客户端刷新，以及非法定义在序列化时失真。修后实际请求消费最终模型的声明，逐个刷新并保留首个错误，原来源认证及其它会话继续正确。

早期一次被称为精确刷新目标反例的测试正文未保全，只能确认同名输入未获回答，不能证明当时已经发出请求。独立补充报告撤回过强表述；当前闭合来自最终同源测试的真实请求、回复和会话隔离，不用后来的成功补写旧证据。

本轮还包含三项必要相邻修复。旧测试句柄按目录回收会误杀同目录的新实例，现只认原句柄；真实保存失败后退出重试曾永久被占用，现失败后可重试，并核第二次真正原子替换及正常退出；输入区收起造成布局收缩，以及正确到达的向下按键与内容增高交错，分别取得真实帧证据后修复。未到时间线的按键前置失败，不用来解释后来的产品顺序缺口。
