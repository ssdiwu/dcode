# 单人本地开发首条路径核对

本片接收有界的单人本地开发路径：命名任务与唯一主会话同次保存，创建身份可防重和查回；空间草稿、命名任务与父任务短期草稿保持正确归属。在同一任务完成“改代码、测试失败、修正、查看差异、追问再修改与测试”，并验证暂停、关闭、只读重开和明确继续。真实工具、命令、保存和界面动作执行，模型服务及目录选择结果仍受控。

## 关键失败与修复

实施前核对发现任务入口和保存回执的真实缺口；追问则是相连证据未覆盖，不是入口未实现。旧任务候选先发布后保存，命名任务缺主会话、父任务草稿归错对象；修后任务、主会话、模型初值与回执确认保存才发布。保存未知只查原身份，前项未知时未发出的新操作明确阻断，不伪造第二个未知保存。

设置页创建成功后仍停在设置页、迟到结果与导航、尚未写盘却误报未知等问题均有旧源反例。相连编码场景实际取得两轮失败与成功出口、两份不同差异；关闭和只读重开保原输入、九个工具身份及请求数量，明确继续才得到新回答。额外计数只证明本场景四次测试命令没有重放，不能概括所有物理工具。
