## 失败、修复与剩余诊断边界

初次全量结果为 29/32，见 [原始失败](e2e-initial.log)，没有删除或覆盖为成功记录。已确认并修复：

- 移植时误删存储保护测试仍使用的 app 绑定，导致 ReferenceError 且清理未执行。恢复绑定；遗留的隔离测试进程经核对后终止，原失败仍计失败。修复后该例及后续存储场景通过。
