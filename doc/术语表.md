# D Code 术语表

本文件只定义项目专有概念；产品行为和验收以当前 PRD 为准。

## Language

**Pi Session（Pi 会话）**：
由 Pi 持久化的一段对话历史及其可恢复运行上下文，是命令行与桌面端共同访问的同一对象。
_Avoid_: Desktop Session、桌面会话副本

**User Home（用户根目录）**：
当前 macOS 用户的主目录，是 D Code 发现全局最近 Pi 会话的默认范围；当前主要使用者对应 `/Users/diwu`。
_Avoid_: 默认项目、会话目录

**Recent Sessions（最近会话）**：
按最后更新时间排列、跨 D Code Project 展示的 Pi Session 视图；它是全局入口，不拥有或复制会话。
_Avoid_: 最近项目、默认项目会话

**D Code Project（D Code 项目）**：
由 D Code 管理、以名称和一组 Source Folder 组织工作上下文的逻辑对象；它不等于 Pi Session，也不等于任一会话的 `cwd`。选中 Project 可直接查看所有 Source Folder 的完整文件树。
_Avoid_: Pi Project、会话文件夹、工作目录分组

**Source Folder（源文件夹）**：
注册到一个 D Code Project 的确切目录，可被选择为新 Pi Session 的 `cwd`；同一 Source Folder 同时最多属于一个项目。它是文件树根节点、搜索筛选项与会话来源说明，不是项目左栏中的会话分组层。
_Avoid_: Project、Session Folder

**Session Path（会话路径）**：
同一 Pi Session 内从根节点到当前节点的一条活动对话路径；切换或续写路径不会创建、切换或还原 Git 分支和项目文件。
_Avoid_: 会话分支、Git 分支

**Composer（输入区）**：
与当前 Pi Session 和 Session Path 绑定的消息输入区域；底部集中显示模型与思考强度、极速开关和上下文占用。Work Inspector 不重复这些控制，只说明当前路径与已加载来源。
_Avoid_: 模型状态栏、右栏模型设置

**Composer Draft（输入草稿）**：
D Code 在本机为特定 Pi Session 与 Session Path 保存、但尚未发送的输入内容；它不是消息，也不是 Pi 会话树节点。
_Avoid_: 待发送消息、Pi 会话草稿节点

**Workspace Tab（工作区标签页）**：
中央工作空间中承载一种内容的可切换页面；第一个固定为 Conversation（对话）且不可关闭，第二个开始承载文件、Artifact 或 Editor，切换时保留各自可恢复状态。
_Avoid_: 消息附件、独立会话、空能力占位页

**File Preview（文件预览）**：
从 Project 文件树打开、在 Workspace Tab 中呈现的文件只读视图；它不是消息、附件或 Context 条目，打开本身不修改文件或 Git 状态。
_Avoid_: Context 附件、文件编辑器

**Live Preview（即时预览）**：
根据当前未保存编辑缓冲区持续呈现 Markdown 或 HTML 结果的 Workspace Tab 视图；Markdown 可在富预览与编辑分栏之间切换，HTML 必须在与宿主界面隔离的执行边界内呈现，不要求用户先保存或停止输入。
_Avoid_: 在宿主页面直接执行 HTML、自动加入模型上下文

**Work Inspector（工作检查器）**：
按当前 Session 或 Project 作用域显示 Goal、Agents、Context、Files 与 Changes 的可折叠右侧区域。
_Avoid_: 常驻仪表盘、终端侧栏

**Agent Team（智能体团队）**：
在当前 Pi Session 中围绕共同目标协作、可彼此通信并向用户呈现工作轨迹、通信与结论的一组 Agent。
_Avoid_: 隐藏思维链面板、独立 Task 列表

**Session Handoff（会话交接）**：
用户在 App 内确认其他客户端已停止使用后，空闲 Pi 会话的写入所有权由 Host 直接取得的过程；不要求 CLI 插件或交接 ID。
_Avoid_: 热迁移、同步写入

**Session Lease（会话租约）**：
D Code Host 在直接接管或新建会话时取得的临时单写入所有权声明；它不改变 Pi Session 本身，也不约束非协作的 Pi CLI。
_Avoid_: 永久锁、会话副本

**Active Plan（活动 Plan）**：
当前 Pi 会话中仍在执行或等待推进的 dgoal Plan；完成后不再属于活动 Plan。
_Avoid_: 任务面板、永久计划栏

**Artifact（产物）**：
由一次消息、工具或能力操作产生的不可变内容快照，例如 Mermaid、原型、文档、图片或 Diff。
_Avoid_: 可覆盖附件、桌面缓存

**Pinned Artifact（固定产物）**：
从原会话引用并提升到项目入口的特定 Artifact；固定不复制或改变原 Artifact。
_Avoid_: 资产副本

**Native Surface（原生呈现面）**：
桌面端根据结构化语义提供的 macOS 交互界面，而非对终端字符画面的截图或解析结果。
_Avoid_: TUI 皮肤

**Pi Host（Pi 宿主）**：
代表桌面端嵌入 Pi SDK、加载 Pi 配置与会话，并拥有会话写入权的本地运行组件；它不启动完整 Pi CLI，也不负责产品界面。
_Avoid_: 第二套 Pi、会话代理数据库

**Unsupported UI Capability（不支持的界面能力）**：
Pi 扩展请求 `custom`、Widget 等依赖 TUI 的界面能力时，D Code 通过结构化事件明确阻止或忽略该操作；不会渲染终端帧，也不会返回虚假成功。
_Avoid_: Compatibility Fallback、静默忽略、伪原生适配
