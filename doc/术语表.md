# D Code 术语表

本文件只定义项目专有概念；产品行为和验收以当前 PRD 为准。

## Language

**Pi Session（Pi 会话）**：
由 Pi 持久化的一段对话历史及其可恢复运行上下文，是命令行与桌面端共同访问的同一对象。
_Avoid_: Desktop Session、桌面会话副本

**D Code Harness（D Code 能力承载与编排层）**：
位于 Agent Runtime 之上的 D Code 产品层，拥有 Project、Goal、Work Item、Team Run、Team Member Run、权限、父子关系、可见事件、报告、证据链接与原生界面；它通过 Host 使用 Pi 等 Runtime 的真实会话和 Agent Loop，不自行复制模型上下文、工具循环或会话历史。
_Avoid_: Pi UI、第二 Agent Loop、通用 Agent Runtime

**Main Agent Session（主智能体会话）**：
用户与主智能体持续工作的稳定 Pi Session，也是 D Team 的协作根；一轮 Team Run 关联其稳定 Session ID 与派发时的 Session Path，同一主会话可以先后拥有多轮 Team Run。主会话不会因为启动成员而改成子会话日志集合。
_Avoid_: Team Run、共享 Worker Session、主会话目录

**Child Agent Session（子智能体会话）**：
某个 Team Member Run 为独立 Agent 工作创建、具有新稳定 ID 的 Pi Session。它在主会话的协作关系与受管执行命名空间下工作，但拥有自己的消息、上下文和运行条目；默认从所属 Team Run 进入，不作为普通会话重复平铺到顶层 Recent 或 Project 列表。它不是主会话的新 Session Path，也不等于临时 Worker Runtime 或工作目录。
_Avoid_: Session Path、主会话副本、Team Member Run

**User Home（用户首页）**：
D Code 的全局入口，以当前 macOS 用户名标识使用者。它不等于用户主目录或默认 Project，也不以文件系统路径作为 Recent Sessions 的发现边界；但从该全局入口开始会话前草稿时，默认把当前 macOS 用户目录作为未来 Pi Session 的 `cwd`。
_Avoid_: 用户根目录、默认项目、会话目录

**Recent Sessions（最近会话）**：
按最后更新时间排列、只展示由 D Code 创建、保留有效来源标记且未被 D Code 归档的 Pi Session 视图。它不拥有或复制会话；旧 Pi Session 在关联对应 Source Folder 后只进入 Project 会话列表。
_Avoid_: 最近项目、默认项目会话

**D Code Session Origin（D Code 会话来源）**：
D Code Host 在创建新 Pi Session 时与 Session Header 一起写入的结构化 Custom Entry。它不进入模型上下文，不包含消息副本；只有标记中的 Session ID 与会话头一致时才能成为 Recent Sessions 的来源证明。
_Avoid_: 桌面会话数据库、路径猜测来源

**D Code Project（D Code 项目）**：
由 D Code 管理、以名称和一组 Source Folder 组织工作上下文的逻辑对象；它不等于 Pi Session，也不等于任一会话的 `cwd`。选中 Project 可直接查看所有 Source Folder 的完整文件树。
_Avoid_: Pi Project、会话文件夹、工作目录分组

**Source Folder（源文件夹）**：
注册到一个 D Code Project 的确切目录，可被选择为新 Pi Session 的 `cwd`；同一 Source Folder 同时最多属于一个项目。它是文件树根节点、搜索筛选项与会话来源说明，不是 Project 在会话栏中的会话分组层。
_Avoid_: Project、Session Folder

**Session Path（会话路径）**：
同一 Pi Session 内从根节点到当前节点的一条活动对话路径；切换或续写路径不会创建、切换或还原 Git 分支和项目文件。
_Avoid_: 会话分支、Git 分支

**Session Copy（会话复制）**：
把一个 Pi Session 的全部已持久化历史复制到所选 Project Source Folder，并创建具有新 Session ID 与新 `cwd` 的独立 Pi Session。源 Session 始终保留；未发送草稿、文件和 Git 状态不会被复制。
_Avoid_: 移动会话、迁移会话、修改会话 `cwd`

**D Code Archive（D Code 归档）**：
以稳定 Session ID 保存的本机、可逆展示状态。归档会话不出现在 Recent、Project 普通列表或 Search 中，但仍保留原 Pi JSONL、可由 Pi CLI 使用，并可从“已归档会话”恢复显示。
_Avoid_: 删除会话、移动会话文件、Pi 归档

**Composer（输入区）**：
与当前 Pi Session 和 Session Path 绑定的消息输入区域；底部集中显示模型与思考强度、极速开关和上下文占用。信息检查器不重复这些控制，只说明当前路径与已加载来源。
_Avoid_: 模型状态栏、信息检查器模型设置

**Composer Draft（输入草稿）**：
D Code 在本机为特定 Pi Session 与 Session Path 保存、但尚未发送的输入内容；它不是消息，也不是 Pi 会话树节点。
_Avoid_: 待发送消息、Pi 会话草稿节点

**Pre-session Draft（会话前草稿）**：
用户点击“新建会话”后、首次提交非空正文前由 D Code 本机拥有的临时输入对象。它只有规范工作目录与非空正文，没有 Pi Session ID、JSONL、来源标记或 Lease；空白内容不持久化，首次发送才创建真实 Pi Session 并转为该 Session 的普通草稿与 Prompt transaction。
_Avoid_: 空 Pi 会话、未发送 Session、临时 Session ID

**Queue Item（队列项）**：
用户在当前 Session Run 执行期间明确加入 Follow-up Queue 的一条普通文本意图。它具有稳定身份并绑定确切 Pi Session 与当前路径谱系锚点；该锚点只可沿当前 Run 或同一队列已确认产生的后继推进，不能因用户选择另一条路径而重绑。派发前由 D Code 本机耐久保存，可编辑、调整顺序或撤回，但不是 Composer Draft、Pi 消息或模型上下文。只有经 Host 派发并取得匹配的 Pi 持久化证据后，它才退出待派发状态。
_Avoid_: 已发送消息、后台任务、Pi 队列副本

**Follow-up Queue（后续消息队列）**：
当前 Pi Session 与 Session Path 内 Queue Item 的有序集合。它不会中断当前 Session Run，只在前一 Run 正常收口且派发门禁成立时逐条继续；失败、中止、等待用户输入、等待权限或身份漂移都会保留队列并暂停自动派发。它不是跨 Session 调度、Work Map 或多 Agent 任务列表。
_Avoid_: Steer、任务队列、跨会话收件箱

**Session Sidebar（会话栏）**：
D Code 工作台左侧的全局导航区域，默认承载新建、搜索、置顶、Recent Sessions、Project 与其会话入口；从 `0.0.6` 起可用铃铛切换到同一可见会话集合的 Activity View。它只负责选择、组织与活动发现，不承载设置、归档管理或文件详情页面。
_Avoid_: 左侧页面、项目页、设置页

**Activity View（活动视图）**：
Session Sidebar 中与默认 Project / 置顶导航互斥的活动投影。它优先显示可靠的等待、当前运行和尚未查看的新完成结果，其余可见 Pi Session 按最后可证明活动时间排列；它不创建新 Session、主页面、标签、任务数据库或后台 Runtime。
_Avoid_: 通知中心、任务页面、多会话调度器

**Run State（运行状态）**：
D Code / Host 能以稳定 Session Run 生命周期、结构化等待请求、失败或持久化事实证明的执行状态。Session 文件更新时间、动画、当前焦点或超时都不能单独构成 Run State。
_Avoid_: User Attention、Session 更新时间、加载动画

**Interaction Dock（交互坞）**：
从 `0.0.6` 起位于 Composer 附近的当前 Session 连续控制面，统一呈现当前活动、Follow-up Queue、等待输入、停止、继续与安全重试。它不是跨 Session 调度、Goal 面板或第二个 Composer。
_Avoid_: Activity View、任务栏、输入区副本

**Main Workspace（主工作区）**：
D Code 工作台中央的主要内容区域。Conversation、Settings、Archived Sessions、Workspace Tab 与后续文件预览都在这里切换；切换页面不会创建第二个应用窗口，也不会把信息检查器变成主内容页。
_Avoid_: 主要页面、中央栏、弹窗容器

**Information Inspector（信息检查器）**：
D Code 工作台右侧的非模态信息区域，按当前 Project、Session 或其他工作对象显示会话、文件、变更与运行上下文。源码中的 `WorkInspector` 是既有内部类型名；用户界面统一称“信息检查器”。
_Avoid_: 右侧页面、文件页、第二主工作区

**Workbench Page（工作台页面）**：
在 Main Workspace 中占据主要内容区的一种导航目的地，例如 Settings 或 Archived Sessions。页面不是独立窗口、Sheet，也不是会话栏或信息检查器。
_Avoid_: 侧栏、弹窗、第二窗口

Settings 是工具型 Workbench Page：进入时可以临时使用完整工作台画布，并以页内设置导航组织子页面；这套页内导航不叫 Session Sidebar，也不会新增第四个固定区域，但会继承会话栏同一份实际宽度。离开 Settings 后，日常会话栏与信息检查器按原有偏好恢复。

**Shared Rail Geometry（共享栏位几何）**：
工作台每个逻辑栏位在整个窗口中只有一份本机持久化的实际宽度。Settings 的页内设置导航与 Session Sidebar 共享左侧栏位宽度；Workspace、Settings、Archived Sessions 及后续 Workbench Page 中任一可调整入口改变该宽度后，其他页面立即继承。Information Inspector 的宽度也在所有 Project、Session 与后续页面间共享。响应式布局可以暂时隐藏或覆盖栏位，但页面不得另设私有默认值、复制宽度状态或在切页时改变用户保存的宽度。
_Avoid_: 设置侧栏宽度、页面局部宽度、宽度副本、每页独立栏位

**Workspace Tab（工作区标签页）**：
Main Workspace 的 Workspace 页面中按需承载文件、Artifact、Preview 或 Editor 的可切换标签。Conversation（对话）是唯一会话主页面而不是标签；没有打开真实内容时不显示标签带，关闭最后一个内容标签后直接回到原会话主页面。各内容标签只保存自己的可恢复内容状态，不拥有或复制 Session / Path / Composer。
_Avoid_: 对话标签、消息附件、独立会话、空能力占位页

**File Preview（文件预览）**：
从 Project 文件树打开、在 Workspace Tab 中呈现的文件只读视图；它不是消息、附件或 Context 条目，打开本身不修改文件或 Git 状态。
_Avoid_: Context 附件、文件编辑器

**Live Preview（即时预览）**：
根据当前未保存编辑缓冲区持续呈现 Markdown 或 HTML 结果的 Workspace Tab 视图；Markdown 可在富预览与编辑分栏之间切换，HTML 必须在与宿主界面隔离的执行边界内呈现，不要求用户先保存或停止输入。
_Avoid_: 在宿主页面直接执行 HTML、自动加入模型上下文

**Goal（目标）**：
D Code 中耐久保存的结果对象，用于说明“最终要达成什么”，并组织对应 Work Item。Goal 不等于 Project、Pi Session、Plan 或一段对话。
_Avoid_: 会话标题、Project Todo、后台调度器

**Work Item（工作项）**：
Goal 下具有稳定身份的可跟踪工作单元，包含状态、依赖、验收条件与完成证据。同一 Work Item 可有多次 Team Run，并关联一个或多个 Session / Path 执行参考；它本身不是 Pi Session，创建后也不会自动执行。
_Avoid_: Todo 对话、Worker 任务、一对一 Pi Session

**Work Map（工作地图）**：
Goal、Work Item、依赖、验收、证据与 User Attention 的可恢复投影视图和控制面。它帮助用户理解“要完成什么”，但不另建一套工作项状态机，也不自动调度执行。
_Avoid_: 后台调度器、Team Run 列表、Todos Cloud 镜像

**Agent Profile（智能体档案）**：
D Code 在本机保存、具有稳定身份与版本的可复用智能体默认配置，包含名称、职责说明、可选默认工作范围与模型路由；完整能力还可引用版本化 Skill 和 Permission Policy。档案不是运行中的 Worker，编辑只影响未来运行，也不会因创建或选择而自动执行。
_Avoid_: Team Run、常驻 Worker、独立 Pi Session

**Agent Team（智能体团队）**：
在当前 Main Agent Session 的一次 Team Run 中，由主智能体派发和协调的一组有界 Worker。每个实际执行成员通过 Team Member Run 关联独立 Child Agent Session；成员可关联 Work Item 或有界证据问题，Finding、Request、指令与交接由主智能体中转，不声称 Worker 直接 P2P。
_Avoid_: 隐藏思维链面板、独立 Task 列表

**Team Run（团队执行）**：
当前 Main Agent Session 为某个 Work Item 或有界问题启动的一次 D Team 执行。它记录主会话与来源路径、成员、子会话引用、来源上下文、可见事件与结构化报告；同一主会话可以拥有多轮 Team Run，关闭一轮执行不会自动将 Work Item 标记为完成。
_Avoid_: Work Item 状态、可跨重启继续的 Worker 进程

**Team Member Run（团队成员执行）**：
Agent Profile 的某个版本在一次 Team Run 中承担具体任务的临时执行记录，保存当次任务、档案快照、实际模型、Effective Grant、声明写入范围、上下文来源、Child Agent Session 与执行目录引用、运行状态、当前活动、请求、发现与报告。子 Pi Session 可以独立持久化，模型生成与工具执行 Runtime 不会因此成为可恢复进程；实例结束后不把运行记录持久化为智能体档案。
_Avoid_: Agent Profile、Work Item、可恢复 Worker 进程

**Skill（技能）**：
由 Pi 或本机已安装能力提供、用于说明“如何完成某类工作”的版本化指令资源。D Code 可以显示其来源、作用、启用状态与兼容性，但 Skill 本身不授予工具、文件、网络或凭据权限，也不成为独立 Agent。
_Avoid_: Permission Grant、云端插件市场、Team Member

**Pi Model Catalog（Pi 模型目录）**：
Pi 当前 Runtime（运行时）可解析的模型集合，包括内置目录、已配置在线目录的本机缓存与 `models.json` 自定义定义。D Code 只按供应商投影这份目录并显示刷新 / 缓存状态，不维护一份竞争性模型清单。
_Avoid_: D Code 模型库、供应商官网镜像、静态模型白名单

**Enabled Model（已启用模型）**：
匹配 Pi `settings.json` 中 `enabledModels` 规则、因此进入 D Code Composer 模型选择器与快捷切换范围的模型。Pi 原生只用这组模式限定模型循环，D Code 明确复用同一来源约束两种选择入口；精确规则与通配规则必须可辨认，不能被单模型操作静默展开。“未在 D Code 中启用”只表示不进入该选择范围，不代表供应商认证、模型可用性或当前 Session 历史被撤销。
_Avoid_: 禁用供应商、模型权限、认证状态

**Custom Model Provider（自定义模型供应商）**：
通过 Pi `models.json` 合同定义、由 Pi Runtime（运行时）加载的供应商和模型集合。D Code 可以提供原生校验与管理界面，但认证仍由 Pi 合同负责，D Code 不展示或保存 API key（API 密钥）、OAuth token（OAuth 令牌）等凭据正文。
_Avoid_: D Code Provider、内置 BYOK（自带密钥）仓库、任意 API（应用程序接口）代理

**D Code Capability Module（D Code 自有能力模块）**：
D Code 为一个明确用户结果拥有的能力合同、生命周期与原生呈现。它可以吸收 `d` 开头扩展的机制，并按需要贡献结构化工具、Host（宿主）服务、状态事件或 presenter（呈现器）；只有真实注册进 Pi Agent Loop（智能体循环）的结构化工具才可由模型调用，Prompt（提示词）描述本身不是工具。
_Avoid_: D 扩展包镜像、第二 Agent Runtime、提示词工具

**Permission Policy（权限策略）**：
Agent Profile 对未来运行可请求能力的默认值与上限；它不是已经生效的工具授权，也不能越过用户或系统的运行时门禁。
_Avoid_: Effective Grant、操作系统沙箱、永久凭据

**Effective Grant（有效授予）**：
Team Member Run 启动时，根据 Permission Policy、用户决定、工具能力和当前范围解析出的不可变权限快照。它只描述本次实际允许的能力，不证明底层已经具有操作系统级强隔离。
_Avoid_: Skill、Profile 默认权限、无限授权

**User Attention（用户关注态）**：
与工作对象和 Run State 分开表达的用户关注事实，例如需要确认计划、回答问题、处理权限、验收结果，或尚未查看某个稳定 Session Run 的新完成结果。关注态可以在执行完成后继续存在，但不能把执行失败、Worker waiting 或普通未读消息当成同义词。
_Avoid_: 执行状态、Worker waiting、普通未读消息

**Cross-Session Message（跨会话消息）**：
D Code 在两个 Pi Session 之间保存的持久、定向、有界交接对象，具有稳定消息身份、来源、目标、送达与恢复状态。它不伪装成普通用户消息，接收 Session 自己决定是否纳入上下文或 Work Map。
_Avoid_: Worker P2P、共享会话内存、运行中热迁移

**Session Observation（会话观察态）**：
D Code 打开既有 Pi Session 后持续读取已落盘历史并跟随外部更新的正常工作状态；它使用完整对话界面与 Composer，不在产品中显示为“只读模式”，也不表示 D Code 已取得写入权。
_Avoid_: 只读会话、桌面会话副本

**Write Intent（写入意图）**：
用户发送消息或修改模型、思考强度、极速等运行设置时表达的明确操作意图；D Code 据此按需争取 Session Lease，不需要额外的“继续会话”确认页。
_Avoid_: 默认接管、同步多写

**Session Lease（会话租约）**：
D Code Host 在明确写入意图或新建会话时取得的临时单写入所有权声明；它不改变 Pi Session 本身，也不约束非协作的 Pi CLI。
_Avoid_: 永久锁、会话副本

**Active Plan（活动 Plan）**：
当前 Session Path 中仍在执行或等待推进的 Plan 紧凑投影；完成后不再属于活动 Plan。D Code 可以识别 dgoal 结构化状态，但产品合同不由该扩展拥有。
_Avoid_: 任务面板、永久计划栏

**Session Run（会话运行轮）**：
D Code 接受一次非空 Prompt 后，由同一 Agent 运行边界产生的一轮执行；使用 D Code Prompt ID 作为稳定 Run ID，并可关联持久化用户条目。Run 属于一个 Pi Session，不能被 Agent turn、工具调用或 Work Item 替代。
_Avoid_: Pi Turn、工具步骤、独立 Session

**Session Change Ledger（会话变更账本）**：
D Code 按稳定 Session ID 持久化的已确认文件变更元数据集合；记录 Run、工具调用、文件、动作、首个变更行与增删行，不保存源码正文或完整补丁。它是覆盖可能不完整的派生投影，不是 Pi Session、Git 或工作区文件的第二权威。
_Avoid_: Git diff、完整审计日志、源码快照

**Change Coverage（变更覆盖度）**：
D Code 对会话变更来源能够证明到什么程度。首版“结构化工具已确认”只证明被观察到的兼容 `edit` / `write`，不能外推为 Bash、外部编辑器、旧历史或整个工作目录的完整归因。
_Avoid_: 全部变更、Git 净变化

**Artifact（产物）**：
由一次消息、工具或能力操作产生的不可变内容快照，例如 Mermaid、原型、文档、图片或 Diff。
_Avoid_: 可覆盖附件、桌面缓存

**Pinned Artifact（固定产物）**：
从原会话引用并提升到项目入口的特定 Artifact；固定不复制或改变原 Artifact。
_Avoid_: 资产副本

**Native Surface（原生呈现面）**：
桌面端根据结构化语义提供的 macOS 交互界面，而非对终端字符画面的截图或解析结果。
_Avoid_: TUI 皮肤

**Pi Host（Pi 宿主）**：
代表桌面端嵌入 Pi SDK、加载 Pi 配置与会话，并拥有会话写入权的本地运行组件；它不启动完整 Pi CLI，也不负责产品界面。
_Avoid_: 第二套 Pi、会话代理数据库

**Unsupported UI Capability（不支持的界面能力）**：
Pi 扩展请求 `custom`、Widget 等依赖 TUI 的界面能力时，D Code 通过结构化事件明确阻止或忽略该操作；不会渲染终端帧，也不会返回虚假成功。
_Avoid_: Compatibility Fallback、静默忽略、伪原生适配
